Usar Mapping Tools en osu! lazer

osu! lazer tiene un flujo de edición de beatmaps distinto al de osu! stable. Mapping Tools puede editar archivos de beatmap de ambos clientes. En lazer, usa el flujo de edición externa y ten en cuenta las limitaciones de algunas funciones.

Cómo usar Mapping Tools en osu! lazer​

En el editor de osu! lazer, selecciona File > Edit externally. Se creará una carpeta temporal con todos los archivos del mapset que estás editando. Mapping Tools la detectará automáticamente y la establecerá como beatmap seleccionado. Cuando termines de editar con Mapping Tools, selecciona Finish editing and import changes para que osu! lazer importe los cambios.

Compatibilidad​

No todas las funciones de Mapping Tools son compatibles con osu! lazer. Esta sección resume la compatibilidad de las funciones.

Las funciones que usan Editor Reader no funcionan en osu! lazer. Si solo piensas usar osu! lazer, se recomienda desactivar Editor Reader en Preferences.

General​

  • ❌ Open current beatmap no funciona.
  • ❌ Current editor time no funciona.
  • ❌ Selected hit objects no funciona.
  • ✅ Generate backup funciona.
  • ✅ Load backup funciona.
  • ✅ Los slider paths con varios tipos de segmentos son totalmente compatibles.

Herramientas​

  • ❌ Geometry Dashboard no funciona; depende de Editor Reader.
  • ✅ Hitsound Copier funciona.
  • 🔶 Hitsound Studio funciona, pero las referencias a muestras importadas y beatmaps dejan de funcionar cuando se elimina la carpeta temporal.
  • ✅ Pattern Gallery funciona.
  • ✅ Property Transformer funciona.
  • ✅ Sliderator funciona, pero el editor de lazer va muy lento.
  • ✅ Tumour Generator 2 funciona.
  • 🔶 Auto-fail Detector funciona, pero auto-fail no existe en lazer.
  • ✅ Combo Colour Studio funciona.
  • ✅ Hitsound Preview Helper funciona.
  • ✅ Map Cleaner funciona.
  • ✅ Mapset Merger funciona.
  • ✅ Metadata Manager funciona.
  • ✅ Rhythm Guide funciona.
  • ✅ Slider Completionator funciona.
  • ✅ Slider Merger funciona.
  • 🔶 Slider Picturator funciona, pero lazer no muestra el slider que contiene la imagen.
  • ✅ Timing Copier funciona.
  • ✅ Timing Helper funciona.

Aviso sobre la compatibilidad futura con lazer​

osu! lazer sigue en desarrollo activo, así que es probable que cambien su cliente y formato de archivos, lo que podría hacer que Mapping Tools dejara de funcionar correctamente. Si tienes un problema al usar Mapping Tools en lazer que no aparezca en esta lista, informa del error con About > Report an issue.
