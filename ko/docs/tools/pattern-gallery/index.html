Pattern Gallery

Pattern Gallery에서는 osu! 비트맵에서 패턴을 가져오고 내보내며, 공유할 패턴 모음을 만들 수 있습니다. 히트오브젝트 배열이나 비트맵의 일부 구간을 다른 비트맵으로 빠르게 옮길 때 유용합니다.

도구 설명​

Pattern Gallery에서는 다음 작업을 할 수 있습니다.

  • osu! 비트맵에서 패턴을 가져오고 내보내 그룹으로 된 히트오브젝트를 비트맵 간에 옮깁니다.
  • 친구와 공유할 패턴 모음을 만듭니다.
  • 아래쪽 버튼으로 패턴을 추가하거나 제거합니다.
  • 패턴을 하나 이상 선택하고 실행 버튼을 누르거나 패턴을 두 번 클릭해 대상 비트맵에 내보냅니다.
  • 내보내는 동안 패턴을 추가 처리하는 옵션을 설정합니다.
  • Project 메뉴에서 패턴 모음을 저장, 불러오기, 이름 변경, 가져오기, 내보내기 할 수 있습니다.

사용 방법​

  1. Mapping Tools에서 Pattern Gallery를 엽니다.
  2. 가져오기 옵션을 사용해 모음에 패턴을 추가합니다.
  3. 갤러리에서 패턴을 선택합니다.
  4. 실행 버튼을 눌러 선택한 비트맵으로 패턴을 내보냅니다.

기능 및 설정​

도구에서 다음 기능을 제공합니다.

  • 패턴 관리: 패턴을 추가, 제거, 이름 변경하고 모음으로 정리합니다.
  • 가져오기 옵션: 선택한 오브젝트, 비트맵 파일, 패턴 코드 등 다양한 소스에서 패턴을 가져옵니다.
  • 내보내기 옵션: 크기 조정, 회전, 필터링 옵션으로 패턴을 내보내는 방식을 설정합니다.

내보내기 옵션​

패턴을 내보낼 때 다음 옵션을 설정할 수 있습니다.

  • Export Offset: 패턴을 배치할 시간을 정합니다. 패턴의 원래 시간, 사용자 지정 시간, 현재 편집기 시간 중에서 선택할 수 있습니다.
    • Custom export offset: 사용자 지정 오프셋 모드에서 패턴을 배치할 시간을 정합니다.
  • Deletion margin: 원본 맵에서 일부를 삭제할 때 패턴 주변에 더할 시간(밀리초)입니다.
  • Parting distance: 패턴을 작은 부분으로 나눌 때 간격에 필요한 최소 박자 수입니다.
  • Beat divisors: 쉼표로 구분해 원하는 비트 분할값을 입력합니다. 예: 1/4, 1/12, 1/7, 4/5, 0.13435622499.
  • Custom Scale: 스칼라 값을 지정해 패턴 크기를 변경합니다.
  • Custom Rotate: 지정한 각도만큼 패턴을 시계 방향으로 회전합니다.
  • Pattern Overwrite Mode: 패턴과 대상 비트맵의 오브젝트가 겹칠 때 처리 방식을 정합니다.
    • NoOverwrite: 비트맵의 기존 오브젝트를 모두 유지합니다. 아무것도 지우지 않고 패턴을 추가합니다.
    • PartitionedOverwrite: 패턴이 밀집된 부분에서만 원본 비트맵의 오브젝트를 제거합니다.
    • CompleteOverwrite: 패턴의 시작 시간과 종료 시간 사이에 있는 원본 비트맵의 오브젝트를 모두 제거합니다.
  • Timing Overwrite Mode: 원본 비트맵과 패턴의 타이밍을 결합하는 방식을 정합니다.
  • Include hitsounds: 패턴의 타이밍 포인트에 지정된 히트사운드 효과를 패턴과 함께 내보냅니다.
  • Include kiai: 패턴의 키아이 설정을 패턴과 함께 내보냅니다.
  • Scale to new circle size: 서클 크기에 대한 간격 비율을 유지하면서 패턴 크기를 조정합니다.
  • Scale to new timing: 새 타이밍에서 오브젝트 사이 박자 수를 유지하도록 패턴 시간을 조정합니다. 스냅되지 않은 레드라인이 있으면 잘못 스냅될 수 있습니다. BPM이 0이거나 무한대인 레드라인이 있으면 사용하지 마세요.
  • Snap to new timing: 지정한 비트 분할값을 사용해 새 타이밍에 패턴 오브젝트를 스냅합니다.
  • Manualify stacks: 패턴의 오브젝트를 수동으로 스택합니다.
  • Fix global SV: 패턴의 그린라인 SV를 새 전역 SV에 맞춰 변경해 새 비트맵에서 슬라이더 SV를 유지합니다.
  • Fix BPM SV: 패턴의 그린라인 SV를 새 BPM에 맞춰 변경해 새 비트맵에서 슬라이더 SV를 유지합니다. Scale to new timing을 사용한다면 이 기능을 끄는 것이 좋습니다.
  • Fix colourhax: 패턴과 원본 비트맵의 오브젝트 색상 인덱스가 같도록 색상 스킵을 조정합니다.
  • Fix slider tick rate: 패턴의 슬라이더 틱 간격을 유지하도록 패턴의 BPM을 조정합니다.

패턴 컨텍스트 메뉴​

갤러리에서 패턴을 마우스 오른쪽 버튼으로 클릭하면 다음 옵션이 표시됩니다.

  • Properties: 이름, 만든 날짜, 마지막 사용 날짜, 사용 횟수 등 패턴 세부 정보를 확인합니다.
  • Delete: 선택한 패턴을 삭제합니다. Shift 키를 누르면 확인 대화상자를 건너뜁니다.
  • Open in File Explorer: 선택한 패턴의 원본 파일을 파일 탐색기에서 엽니다.
  • Group: 패턴을 그룹으로 정리하는 옵션입니다.

가져오기 옵션​

가져오기 버튼을 누르면 여러 소스에서 패턴을 가져올 수 있습니다.

  • Import Selected: 편집기에서 현재 선택한 히트오브젝트로 패턴을 만듭니다.
    • Name: 패턴 이름입니다.
  • Import from .osu File: 드라이브에 있는 .osu 파일에서 패턴을 가져옵니다.
    • Name: 패턴 이름입니다.
    • Pattern file path: 가져올 패턴 파일의 경로입니다.
    • Filter: .osu 파일의 필터입니다.
    • Start Time: 패턴을 시작할 .osu 파일 안의 시간입니다.
    • End Time: 패턴을 끝낼 .osu 파일 안의 시간입니다.
  • Import from Code: 온라인에서 공유하는 패턴 코드를 가져옵니다.
    • Name: 패턴 이름입니다.
    • Hit Objects: 히트오브젝트 코드입니다.
    • Timing Points: 타이밍 포인트 코드입니다.
    • Global SV: 패턴 히트오브젝트의 전역 슬라이더 속도를 설정합니다.
    • Game Mode: 패턴에 사용할 게임 모드를 설정합니다.

Project 메뉴​

Pattern Gallery의 Project 메뉴에서 다음 작업을 할 수 있습니다.

  • 패턴 모음 저장
  • 패턴 모음 불러오기
  • 패턴 모음 이름 변경
  • 패턴 모음 가져오기
  • 패턴 모음 내보내기
