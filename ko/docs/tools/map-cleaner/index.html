Map Cleaner

Map Cleaner는 대상 비트맵에서 쓸모없는 그린라인을 정리하고, 비트맵 전체에 적용할 수 있는 여러 작업도 제공합니다.

Map Cleaner는 모든 타이밍 포인트를 다시 구성하는 방식으로 작동합니다. 먼저 타이밍 포인트가 각각 미치는 영향을 저장한 다음 체계적인 방식으로 다시 만듭니다. 이 과정에서 그린라인은 이를 사용하는 오브젝트에 자동으로 다시 스냅되고, 불필요한 변경은 제거됩니다. 추가 기능을 사용하지 않는 한 비트맵과 히트사운드는 사실상 그대로 유지되며, 편집기에 표시되는 내용만 달라집니다.

맵 정보 설정​

이 설정은 Map Cleaner가 타이밍 포인트에서 어떤 항목을 제거할지 결정합니다. 안전하게 정리하려면 모든 항목을 선택해 제거되는 데이터를 최소화할 수 있습니다.

  • Map uses volume changes in sliders: 슬라이더 몸통 구간의 볼륨 변경이 의도된 것이며 제거하지 않아야 한다고 Map Cleaner에 알립니다.
  • Map uses sampleset changes in sliders: 슬라이더 몸통 구간의 샘플 세트 또는 샘플 인덱스 변경이 의도된 것이며 제거하지 않아야 한다고 알립니다.
  • Map uses volume changes in spinners: 스피너 구간의 볼륨 변경이 의도된 것이며 제거하지 않아야 한다고 알립니다.

추가 기능​

다음 작업은 Map Cleaner의 기본 정리와 함께 실행할 수 있습니다.

  • Resnap objects: 맵을 정리하는 동안 모든 히트오브젝트와 슬라이더 끝을 다시 스냅합니다. 설정된 비트 분할값에 맞춰 스냅합니다.
  • Resnap bookmarks: 기본 스냅 방식으로 모든 북마크를 다시 스냅합니다. 비정상적인 비트 분할값에 맞춘 북마크가 있다면 이 옵션을 해제하는 것이 좋습니다.
  • Remove unused samples: 맵셋 내 비트맵과 스토리보드에서 사용하지 않는 모든 오디오 샘플을 제거합니다. 비트맵 스킨에서 불러오는 샘플은 무시합니다.
  • Remove muting: 볼륨이 5%인 히트사운드의 볼륨 변경과 사용자 지정 인덱스 변경을 제거합니다. 타이밍 포인트의 볼륨이 5%이면 해당 타이밍 포인트의 볼륨 변경과 사용자 지정 인덱스 변경을 제거합니다.
  • Mute unclickable hitsounds: 플레이어의 입력이 필요하지 않은 히트오브젝트에서 발생하는 히트사운드의 볼륨을 5%로 설정합니다. 서클, 슬라이더 헤드, 홀드 노트 헤드만 들리게 됩니다. 맵의 리듬이나 실제 플레이 감각을 더 잘 파악할 때 유용합니다.

다시 스냅​

다시 스냅할 때는 타임라인에서 가장 가까운 틱으로 이동한 뒤 정수 시간으로 내림합니다. 히트오브젝트 시간에서 10ms 이내에 레드라인이 있으면 대신 해당 레드라인에 스냅합니다. 레드라인보다 3ms 앞선 틱으로 잘못 스냅되는 일을 막기 위한 동작입니다.

슬라이더 끝을 다시 스냅하는 방법은 두 가지입니다. 첫 번째 방법은 슬라이더의 지속 시간을 비트 분할값의 가장 가까운 배수로 바꿉니다. 기본 osu! 편집기에서 슬라이더를 선택하고 §Ctrl+Shift+S§를 누르는 것과 비슷합니다.

슬라이더 구간 안에 레드라인이 있거나 슬라이더 끝에서 20ms 이내에 레드라인이 있는 경우에는 두 번째 방법을 사용합니다. 새 타이밍에서 가장 가까운 틱으로 슬라이더의 종료 시간을 스냅합니다. 이 방법은 정수 지속 시간의 슬라이더를 만들지만, 타임라인 틱에서 반올림되므로 정확한 길이는 달라질 수 있습니다.

모든 스피너 끝과 홀드 노트 끝도 두 번째 방법으로 다시 스냅합니다.

대상 비트맵의 게임 모드가 osu!mania이면 노트의 X 위치도 열의 가운데로, Y 위치도 192로 다시 스냅합니다.

타임라인​

Map Cleaner를 실행하면 프로그램이 타이밍 포인트에 적용한 변경이 작은 타임라인에 표시됩니다.

  • 빨간색 선은 제거된 타이밍 포인트입니다.
  • 주황색 선은 변경된 타이밍 포인트입니다.
  • 초록색 선은 추가된 타이밍 포인트입니다.

타이밍 포인트의 위치만 이동한 경우 이전 위치에는 빨간색 선, 새 위치에는 초록색 선이 표시됩니다.

타임라인의 선을 두 번 클릭하면 편집기가 해당 시간으로 이동합니다.
