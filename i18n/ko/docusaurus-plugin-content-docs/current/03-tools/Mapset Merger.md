Mapset Merger는 여러 맵셋을 하나의 큰 맵셋으로 병합하는 도구입니다.

파일 충돌이 생기면 가능한 한 많은 파일을 별도의 하위 폴더로 옮기고, 사용자 지정 히트사운드의 샘플 세트를 다시 구성해 자동으로 해결합니다. 안타깝게도 비트맵에서 명시적으로 참조하지 않는 비트맵 스킨과 사용자 지정 스피너 히트사운드는 병합할 수 없습니다. 이 파일들은 맵셋 전체에 영향을 주기 때문입니다.

## 맵셋 추가 {#adding-mapsets}

맵셋을 추가하려면 오른쪽 아래의 더하기 버튼을 누르세요. 현재 대상 비트맵의 맵셋 정보가 미리 입력된 새 맵셋이 목록에 추가됩니다. 더하기 버튼을 **Shift 키를 누른 채 클릭**하면 osu! 클라이언트에서 현재 열려 있는 맵셋을 사용합니다.

병합할 맵셋이 목록에 표시됩니다. 각 맵셋에는 이름과 루트 폴더 경로가 있습니다. 병합된 맵셋 안의 파일을 분류할 때 맵셋 이름을 사용하므로, 이름은 서로 겹치지 않고 간결하게 정하세요. 목록에서 경로를 **두 번 클릭**해 수정할 수 있습니다. 그러면 파일 탐색기에서 경로를 고를 수 있는 찾아보기 버튼도 표시됩니다.

## 내보내기 {#exporting}

실행 버튼을 누르면 맵셋을 병합해 **Export path** 폴더에 내보냅니다. 폴더가 없으면 오류가 발생하므로 미리 만들어 두세요.

**Move storyboard to .osu**를 선택하면 맵셋 안에 있는 모든 .osb 파일의 내용을 각 .osu 파일로 옮깁니다. 이렇게 하면 스토리보드가 특정 비트맵에만 적용되어, 병합된 다른 맵셋에 영향을 주지 않습니다. 스토리보드가 서로 다른 맵셋을 병합할 때 유용하지만, 스토리보드 파일이 크고 난이도가 여러 개라면 데이터가 복제되어 .osu 파일 크기가 크게 늘 수 있으니 주의하세요.
