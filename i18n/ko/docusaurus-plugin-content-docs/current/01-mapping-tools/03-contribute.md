Mapping Tools는 다음 두 GitHub 저장소를 중심으로 개발됩니다.

### Mapping Tools

Mapping Tools의 데스크톱 애플리케이션입니다.

https://github.com/OliBomby/Mapping_Tools

### Mapping Tools Website

현재 보고 있는 웹사이트입니다. Mapping Tools에 관한 지식을 웹에 공유합니다.

https://github.com/mappingtools/mappingtools.github.io

## 더 이상 개발되지 않는 프로젝트

다음 프로젝트는 더 이상 활발히 개발되지 않지만, 여전히 유용할 수 있습니다.

### Mapping Tools Core

.NET 개발자를 위한 Mapping Tools 백엔드 패키지입니다. 다른 프로그램에서 Mapping Tools 기능을 사용할 수 있습니다.

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

Mapping Tools Core를 사용하며 완전히 크로스 플랫폼을 지원하는 Mapping Tools 웹 버전입니다.

https://github.com/misakura-rin/mapping-tools-web
