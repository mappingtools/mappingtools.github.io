Mapping Tools는 osu! 매핑을 위한 여러 도구를 **하나의 애플리케이션**으로 모은 모음입니다.
손으로 했다면 몇 시간 걸릴 비트맵 수정 작업을 빠르게 처리할 수 있습니다.
모든 도구에서 백업과 메모리 읽기 같은 **편의 기능**을 공유하므로, 언제나 빠르고 믿을 수 있는 도구를 사용할 수 있습니다.

![Mapping Tools 로고](/img/mt_banner.png)

## 시작하기 {#get-started}

**가이드**를 따라 하거나 [**동영상 튜토리얼**](https://www.youtube.com/playlist?list=PLuijZnrwVA86pO7zIP9oVu-7YAQ5qEe2Y)을 시청해 Mapping Tools를 빠르게 익혀 보세요.

1. Mapping Tools를 [**설치**](02-installation.md)하고 실행합니다.

2. Mapping Tools를 [**설정**](02-installation.md#setup)합니다.

3. **File > Open (current) beatmap**으로 비트맵을 선택합니다.

4. 탐색 메뉴에서 도구로 이동합니다: `Ctrl+K`

5. 설정을 마친 뒤 오른쪽 아래의 실행 버튼을 누릅니다.

6. 저장하지 않고 비트맵을 다시 불러옵니다: `Ctrl+L, Enter`

## 기능 {#features}

Mapping Tools는 자유로운 사용을 염두에 두고 만들어졌으며, 간단한 도구의 효용을 최대한 끌어냅니다.

- **Map Cleaner**
  - 쓸모없는 그린라인 제거
  - 그린라인, 히트오브젝트, 북마크의 스냅 재설정
  - 사용하지 않는 히트사운드 샘플 제거
- **Metadata Manager**
  - 맵셋 전체의 메타데이터를 한 번에 편집
  - 중복 태그 제거
- **Property Transformer**
  - 모든 타이밍 포인트 또는 히트오브젝트의 타이밍을 이동하거나 배율 조정
  - 여러 그린라인의 볼륨, 인덱스 또는 슬라이더 속도를 한 번에 변환
- **Slider Merger**
  - 여러 슬라이더와 서클을 합쳐 원래 모양을 결합한 하나의 큰 슬라이더 생성
- **Slider Completionator**
  - 슬라이더의 지속 시간 또는 길이 설정
  - 4배를 넘는 슬라이더 속도 구현
- **Timing Copier**
  - 비트맵 간 타이밍 복사
  - 오브젝트를 새 타이밍에 맞춰 자동으로 다시 스냅하고 배율 조정
- **Timing Helper**
  - 복잡한 타이밍을 더 빠르게 생성
- **Hitsound Copier**
  - 비트맵 간 히트사운드 복사
  - 누락된 히트사운드를 대신해 스토리보드 샘플 복사
  - 슬라이더 틱과 슬라이더 이동음에 히트사운드 복사
  - 슬라이더 끝의 소리 자동 음소거
- **Hitsound Studio**
  - [osu!mania 히트사운드를 osu!standard 히트사운드로 변환](../04-guides/hs-studio-convert-mania-to-standard.md)
  - 여러 맵셋의 사용자 지정 히트사운드를 하나의 맵셋으로 합치기
  - MIDI를 키 사운드로 변환
- **Hitsound Preview Helper**
  - 위치에 따라 오브젝트에 히트사운드 배치
  - Hitsound Studio와 호환되는 히트사운드 맵을 쉽게 생성
- **Rhythm Guide**
  - 비트맵에서 리듬을 추출해 히트사운드 작업의 참고 자료로 사용
- **Geometry Dashboard**
  - 매핑 중 참고할 수 있도록 편집기 위에 실시간 기하 도형 표시
- **Combo Colour Studio**
  - 컬러핵을 쉽게 생성
  - 비트맵 간 컬러핵 복사
- **Sliderator**
  - 슬라이더 중간에서 슬라이더 속도 변경
  - 가속 또는 감속하는 스트림 생성
- **Auto-fail Detector**
  - 2B 스타일 비트맵에서 오토 페일 감지
  - 오토 페일 자동 수정
- **Pattern Gallery**
  - 매핑 패턴 모음을 만들고 공유
  - 비트맵 간 패턴 복사
- **Mapset Merger**
  - 여러 맵셋을 하나의 큰 맵셋으로 병합
- **Tumour Generator**
  - 슬라이더 양옆에 다양한 모양 추가
  - 새로운 방식으로 슬라이더 전체 설계
- **Slider Picturator**
  - 이미지를 슬라이더로 변환해 비트맵에 배치
