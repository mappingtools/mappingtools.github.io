Mapping Tools를 실행하면 기본으로 시작 화면이 열립니다. 이 화면에는 애플리케이션 변경 내역과 Mapping Tools에서 최근에 사용한 맵 목록이 표시됩니다. 탐색 메뉴에서도 이 화면으로 이동할 수 있습니다.

화면 위쪽의 파란색 표시줄에는 탐색 메뉴 버튼과 메뉴, _Selected beatmap_ 표시가 있습니다. 대부분의 매핑 도구는 이 비트맵을 대상으로 작업합니다.

탐색 메뉴 버튼을 누르면 왼쪽에 Mapping Tools의 모든 페이지로 이동할 수 있는 메뉴가 열립니다. 검색창에 페이지 이름을 입력하고 `Enter`를 누르면 가장 먼저 검색된 결과로 이동할 수 있습니다. 언제든 `Ctrl+K`를 눌러 탐색 메뉴를 열 수 있습니다.

### File {#file}

**File** 메뉴에는 비트맵 파일을 선택하고 불러오거나 저장하는 버튼이 있습니다.

- **Open beatmap**은 파일 탐색기를 열어 선택한 하나 이상의 비트맵을 대상 비트맵으로 설정합니다.
- **Open current beatmap**은 osu! 클라이언트에서 현재 선택된 비트맵을 대상 비트맵으로 설정합니다.
- **Generate backup**은 대상 비트맵의 백업을 만듭니다.
- **Load backup**은 파일 탐색기를 열어 백업 비트맵을 선택하고 대상 비트맵에 불러옵니다.
- **QuickUndo**는 주기 백업이 아닌 가장 최근 백업을 대상 비트맵에 불러옵니다.
- **BetterSave™ current beatmap**은 _osu!_ 편집기에서 현재 열려 있는 비트맵을 좌표를 자르는 대신 반올림하여 저장합니다.

### About {#about}

**About** 메뉴에서 Mapping Tools에 관한 정보와 유용한 링크를 확인할 수 있습니다.

- **Open backups folder**는 Mapping Tools가 만든 모든 백업이 들어 있는 폴더를 엽니다.
- **Open Mapping Tools folder**는 설정, 백업, 내보내기 파일 등 Mapping Tools가 만든 모든 파일이 들어 있는 폴더를 엽니다.

### Project {#project}

**Project** 메뉴는 매핑 도구 화면을 보고 있을 때만 표시됩니다. 여기에서 해당 도구의 설정을 저장하고 불러올 수 있습니다.
