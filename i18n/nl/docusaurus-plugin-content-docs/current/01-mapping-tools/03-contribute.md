De ontwikkeling van Mapping Tools vindt voornamelijk plaats in deze twee GitHub-repositories:

### Mapping Tools

De hoofdapplicatie voor desktop van Mapping Tools.

https://github.com/OliBomby/Mapping_Tools

### Mapping Tools-website

De website waarop je je nu bevindt. Hier delen we kennis over Mapping Tools met de rest van de wereld.

https://github.com/mappingtools/mappingtools.github.io

## Verouderde projecten

Deze projecten worden niet meer actief ontwikkeld, maar kunnen nog steeds nuttig zijn.

### Mapping Tools Core

Het back-endpakket van Mapping Tools voor .NET-ontwikkelaars. Hiermee kunnen andere programma's functies van Mapping Tools gebruiken.

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

De webversie van Mapping Tools. Deze gebruikt Mapping Tools Core en werkt op alle platforms.

https://github.com/misakura-rin/mapping-tools-web
