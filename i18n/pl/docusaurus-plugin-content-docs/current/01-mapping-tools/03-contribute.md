Główne prace nad Mapping Tools odbywają się w tych dwóch repozytoriach GitHub:

### Mapping Tools

Główna aplikacja desktopowa Mapping Tools.

https://github.com/OliBomby/Mapping_Tools

### Strona Mapping Tools

Strona, na której teraz jesteś. Przybliża Mapping Tools całemu światu.

https://github.com/mappingtools/mappingtools.github.io

## Przestarzałe projekty

Te projekty nie są już aktywnie rozwijane, ale nadal mogą się przydać.

### Mapping Tools Core

Pakiet backendowy Mapping Tools dla programistów .NET. Umożliwia innym programom korzystanie z funkcji Mapping Tools.

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

Wersja internetowa Mapping Tools. Korzysta z Mapping Tools Core i jest w pełni wieloplatformowa.

https://github.com/misakura-rin/mapping-tools-web
