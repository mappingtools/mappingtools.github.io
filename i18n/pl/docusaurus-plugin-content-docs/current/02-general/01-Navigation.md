Mapping Tools domyślnie otwiera ekran Pierwsze kroki, na którym znajduje się dziennik zmian aplikacji oraz lista map ostatnio używanych w Mapping Tools. Do tego ekranu można też przejść z menu nawigacji.

U góry ekranu znajduje się niebieski pasek z przyciskiem menu nawigacji, menu oraz informacją o _wybranej beatmapie_. To beatmapa, nad którą pracuje większość narzędzi do mapowania.

Przycisk nawigacji otwiera po lewej stronie menu, z którego przejdziesz do wszystkich stron w Mapping Tools. Znajduje się w nim pasek wyszukiwania: wpisz nazwę strony i naciśnij `Enter`, aby przejść do pierwszego wyniku. Menu nawigacji można w każdej chwili otworzyć skrótem `Ctrl+K`.

### File {#file}

Menu **File** zawiera przyciski do wybierania, wczytywania i zapisywania plików beatmap.

- **Open beatmap** otwiera eksplorator plików, w którym można wybrać jedną lub więcej beatmap jako wybrane beatmapy.
- **Open current beatmap** wybiera beatmapę aktualnie otwartą w kliencie _osu!_.
- **Generate backup** tworzy kopię zapasową wybranej beatmapy.
- **Load backup** otwiera eksplorator plików, aby wybrać kopię zapasową do wczytania do wybranej beatmapy.
- **QuickUndo** wczytuje do wybranej beatmapy najnowszą kopię zapasową, która nie jest okresowa.
- **BetterSave™ current beatmap** zapisuje beatmapę otwartą w edytorze _osu!_, zaokrąglając współrzędne zamiast je obcinać.

### About {#about}

Menu **About** zawiera dodatkowe informacje i przydatne odnośniki związane z Mapping Tools.

- **Open backups folder** otwiera folder ze wszystkimi kopiami zapasowymi utworzonymi przez Mapping Tools.
- **Open Mapping Tools folder** otwiera folder ze wszystkimi plikami tworzonymi przez Mapping Tools, takimi jak ustawienia, kopie zapasowe i eksporty.

### Project {#project}

Menu **Project** jest widoczne tylko na ekranie jednego z narzędzi do mapowania. Zawiera przyciski do zapisywania i wczytywania ustawień danego narzędzia.
