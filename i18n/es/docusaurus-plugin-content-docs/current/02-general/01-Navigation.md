De forma predeterminada, Mapping Tools se abre en la pantalla de inicio, que contiene el registro de cambios de la aplicación y una lista de los mapas usados más recientemente con Mapping Tools. También puedes abrir esta pantalla desde el menú de navegación.

En la parte superior de la pantalla hay una barra azul con el botón para abrir el menú de navegación, los menús y la información del _beatmap seleccionado_. Este es el beatmap en el que trabajará la mayoría de las herramientas.

El botón de navegación abre un menú a la izquierda que permite acceder a todas las páginas de Mapping Tools. Puedes escribir el nombre de una página en la barra de búsqueda y pulsar `Enter` para abrir el primer resultado. También puedes usar `Ctrl+K` en cualquier momento para abrir el menú.

### File {#file}

El menú **File** contiene botones para seleccionar, cargar y guardar archivos de beatmap.

- **Open beatmap** abre el explorador de archivos para seleccionar uno o varios beatmaps como beatmap seleccionado.
- **Open current beatmap** selecciona el beatmap que está seleccionado en el cliente de _osu!_.
- **Generate backup** crea una copia de seguridad del beatmap seleccionado.
- **Load backup** abre el explorador de archivos para seleccionar una copia de seguridad y cargarla en el beatmap seleccionado.
- **QuickUndo** carga en el beatmap seleccionado la copia de seguridad no periódica más reciente.
- **BetterSave邃｢ current beatmap** guarda el beatmap abierto en el editor de _osu!_ y redondea las coordenadas en lugar de truncarlas.

### About {#about}

El menú **About** ofrece información adicional y enlaces útiles sobre Mapping Tools.

- **Open backups folder** abre la carpeta que contiene todas las copias de seguridad creadas por Mapping Tools.
- **Open Mapping Tools folder** abre la carpeta que contiene los archivos creados por Mapping Tools, como ajustes, copias de seguridad y exportaciones.

### Project {#project}

El menú **Project** solo aparece al ver la pantalla de una herramienta. Contiene opciones para guardar y cargar ajustes específicos de esa herramienta.
