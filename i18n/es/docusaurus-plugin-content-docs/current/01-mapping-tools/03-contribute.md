El desarrollo principal de Mapping Tools se realiza en estos dos repositorios de GitHub:

### Mapping Tools

La aplicación de escritorio principal de Mapping Tools.

https://github.com/OliBomby/Mapping_Tools

### Sitio web de Mapping Tools

El sitio web que estás visitando. Comparte con todo el mundo información sobre Mapping Tools.

https://github.com/mappingtools/mappingtools.github.io

## Proyectos obsoletos

Estos proyectos ya no se desarrollan activamente, aunque aún pueden ser útiles.

### Mapping Tools Core

Paquete de back-end de Mapping Tools para desarrolladores de .NET. Permite que otros programas usen las funciones de Mapping Tools.

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

La versión web de Mapping Tools. Usa Mapping Tools Core y es totalmente compatible con varias plataformas.

https://github.com/misakura-rin/mapping-tools-web
