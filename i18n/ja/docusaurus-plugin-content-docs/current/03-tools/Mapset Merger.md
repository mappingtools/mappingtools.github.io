Mapset Merger は、複数のマップセットをひとつの大きなマップセットに統合するツールです。

このツールはファイルの競合を自動的に解決します。できるだけ多くのファイルを個別のサブフォルダーへ移し、カスタムヒットサウンドのサンプルセットを再構築します。ただし、譜面に明示的に参照されていない譜面スキンとカスタムスピナーヒットサウンドは統合できません。これらのファイルは常にマップセット全体に影響するためです。

## マップセットの追加 {#adding-mapsets}

マップセットを追加するには、右下のプラスボタンを押します。選択中の譜面のマップセット情報があらかじめ入力された状態で、コレクションに追加されます。プラスボタンを**Shift キーを押しながらクリック**すると、代わりに osu! クライアントで現在開いているマップセットが使われます。

統合するすべてのマップセットが一覧に表示されます。各マップセットには名前とルートフォルダーのパスがあります。結合後のマップセット内でファイルを分類するために名前を使うので、重複しない短い名前を付けてください。一覧のパスを**ダブルクリック**すると編集できます。ファイルエクスプローラーからパスを選択するための参照ボタンも表示されます。

## エクスポート {#exporting}

実行ボタンを押すとマップセットが統合され、**Export path** に指定されたフォルダーへファイルがエクスポートされます。このフォルダーが存在しない場合はエラーになるので、事前に作成してください。

**Move storyboard to .osu** をオンにすると、マップセット内の .osb ファイルの内容が .osu ファイルに移されます。ストーリーボードが譜面ごとになるため、統合後の別のマップセットに混入しなくなります。異なるストーリーボードを持つマップセットを結合する場合に便利です。ただし、ストーリーボードファイルが大きく、複数の難易度があるマップセットでは、データが難易度の数だけ複製されて .osu ファイルが大きくなることがあるので注意してください。
