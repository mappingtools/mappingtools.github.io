Map Cleaner は、Selected beatmap から不要な緑線を削除し、譜面全体に対するその他の便利な操作も行えます。

Map Cleaner はすべてのタイミングポイントを再構築して処理します。まずタイミングポイントの影響をすべて記録し、その後、整理された形で再構築します。その際、緑線は影響を受けるオブジェクトに合わせて自動的に再スナップされ、不要な変更は取り除かれます。
追加機能を有効にしていない限り、この処理によって譜面やヒットサウンドが変わることは基本的にありません。変更は主にエディター上で確認できます。

## 譜面情報の設定 {#map-info-settings}

これらの設定は、Map Cleaner がタイミングポイントから何を削除するかを指定します。
安全を優先する場合はすべてオンにしてください。削除される項目を最小限にできます。

- **Map uses volume changes in sliders**: オンにすると、スライダーの途中の音量変更は*意図的*なものとして扱われ、削除されません。
- **Map uses sampleset changes in sliders**: オンにすると、スライダー途中のサンプルセットやサンプルインデックスの変更は*意図的*なものとして扱われ、削除されません。
- **Map uses volume changes in spinners**: オンにすると、スピナー中の音量変更は*意図的*なものとして扱われ、削除されません。

## 追加機能 {#additional-features}

Map Cleaner の通常の処理に加えて実行できる操作です。

- **Resnap objects**: 譜面のクリーニング中にすべてのヒットオブジェクトを再スナップし、スライダー終端も再スナップします。再スナップにはビート分割設定を使います。
- **Resnap bookmarks**: 既定の再スナップ方法ですべてのブックマークを再スナップします。通常と異なるビート分割に合わせてブックマークを置いている場合は、オフにするとよいでしょう。
- **Remove unused samples**: マップセット内の譜面やストーリーボードのいずれからも使われていないオーディオサンプルをすべて削除します。譜面のスキンで設定できるサンプルは対象外です。
- **Remove muting**: 音量 5% のヒットサウンドに設定された音量変更とカスタムインデックス変更を削除します。タイミングポイントに 5% の音量が設定されている場合、その音量変更とカスタムインデックス変更が削除されます。
- **Mute unclickable hitsounds**: プレイヤーの操作を必要としないヒットオブジェクトから発生するヒットサウンドイベントをすべて音量 5% にします。クリックできるのは円、スライダーの始点、ホールドノートの始点だけです。譜面のリズムやプレイ感を把握するのに役立ちます。

## 再スナップ

再スナップでは、タイムライン上の最も近い目盛りに合わせてから、時間を整数に切り下げます。ヒットオブジェクトの時刻から 10 ms 以内の後ろに赤線がある場合は、その赤線にスナップします。これにより、赤線の 3 ms 前にある目盛りへ再スナップされるのを防ぎます。

スライダー終端の再スナップには 2 つの方法があります。1 つ目は、スライダーの長さを取得して最も近いビート分割の倍数に変更する方法です。osu! エディターでスライダーを選択して `Ctrl+Shift+S` を押す操作に似ています。

2 つ目の方法は、スライダー中またはスライダー終了後 20 ms 以内に赤線がある場合だけ使われます。スライダーの終了時刻を、新しいタイミング上の最も近い目盛りにスナップします。これにより長さは整数になりますが、タイムラインの丸めによって正確な長さにはずれが生じます。

すべてのスピナーとホールドノートの終端も 2 つ目の方法で再スナップされます。

Selected beatmap が osu! mania の場合、再スナップ時にノートの X 座標も列の中央、Y 座標も 192 に合わせられます。

## タイムライン

Map Cleaner を実行すると、プログラムがタイミングポイントに加えた変更を示すタイムラインが表示されます。

- 赤線はタイミングポイントの削除を示します。
- オレンジ線はタイミングポイントの変更を示します。
- 緑線はタイミングポイントの追加を示します。

タイミングポイントが移動した場合は、移動前の位置に赤線、移動後の位置に緑線が表示されます。

タイムラインの線を**ダブルクリック**すると、エディターでその時刻に移動できます。
