Pattern Gallery では、osu! の譜面からパターンをインポート、エクスポートし、共有可能なパターンコレクションを作成できます。ヒットオブジェクトの並びや譜面の一部を、異なる譜面間ですばやく移動するのに最適なツールです。

## ツールの説明

Pattern Gallery では、次のことができます。

* osu! の譜面からパターンをインポート、エクスポートし、ヒットオブジェクトのグループを譜面間で移動する。
* 友達と共有できるパターンコレクションを作成する。
* 画面下部のボタンからパターンを追加、削除する。
* ギャラリーで 1 つ以上のパターンを選択して実行ボタンを押すか、パターンをダブルクリックして Selected beatmap にエクスポートする。
* エクスポート時に追加処理を行う設定を利用する。
* **Project** メニューからパターンコレクションを保存、読み込み、名前変更、インポート、エクスポートする。

## 使い方

1. Mapping Tools で Pattern Gallery を開きます。
2. インポート機能を使ってコレクションにパターンを追加します。
3. ギャラリーからパターンを選択します。
4. 実行ボタンを押してパターンを Selected beatmap にエクスポートします。

## 機能と設定

次の機能を利用できます。

* **パターン管理**: パターンの追加、削除、名前変更、コレクション内での整理。
* **インポート設定**: 選択中のオブジェクト、譜面ファイル、パターンコードなど、さまざまなソースからパターンをインポート。
* **エクスポート設定**: 拡大縮小、回転、フィルターなどを指定してパターンをエクスポート。

## エクスポート設定

パターンをエクスポートするときは、次の設定を調整できます。

* **Export Offset**: パターンを配置する時刻を指定します。元の時刻、カスタム時刻、現在のエディター時刻から選択できます。
  * **Custom export offset**: カスタムオフセットモードでパターンを配置する時刻を指定します。
* **Deletion margin**: 元の譜面の一部を削除する際、パターンの前後に追加する時間 (ms) です。
* **Parting distance**: パターンを小さな部分に分割する場合に必要な、間隔の最小ビート数です。
* **Beat divisors**: ビート分割をカンマ区切りで任意の数だけ入力します。例: 1/4, 1/12, 1/7, 4/5, 0.13435622499。
* **Custom Scale**: スカラー値を指定してパターンのサイズを変更します。
* **Custom Rotate**: 指定した角度だけパターンを時計回りに回転します。
* **Pattern Overwrite Mode**: パターンとエクスポート先の譜面でオブジェクトが重なる場合の処理方法です。
  * **NoOverwrite**: 譜面の既存オブジェクトをすべて残します。パターンは何も削除せずに追加されます。
  * **PartitionedOverwrite**: パターンの密度が高い部分でのみ、元の譜面のオブジェクトを削除します。
  * **CompleteOverwrite**: パターンの開始時刻から終了時刻まで、元の譜面にあるオブジェクトをすべて削除します。
* **Timing Overwrite Mode**: 元の譜面とパターンのタイミングをどのように組み合わせるか指定します。
* **Include hitsounds**: パターンのタイミングポイントにあるヒットサウンド効果もエクスポートします。
* **Include kiai**: パターンの kiai もエクスポートします。
* **Scale to new circle size**: サークルサイズに対する間隔が変わらないよう、パターンを拡大縮小します。
* **Scale to new timing**: 新しいタイミングでもオブジェクト間のビート数が変わらないよう、パターンの時間を拡大縮小します。赤線のタイミングがずれているとスナップが誤ることがあります。BPM が 0 または無限大の赤線がある場合は使わないでください。
* **Snap to new timing**: 指定したビート分割を使って、パターンのオブジェクトを新しいタイミングにスナップします。
* **Manualify stacks**: パターンのオブジェクトを手動でスタックします。
* **Fix global SV**: パターン内の緑線の SV を新しい Global SV に合わせて調整し、新しい譜面でもスライダーの SV が変わらないようにします。
* **Fix BPM SV**: パターン内の緑線の SV を新しい BPM に合わせて調整し、新しい譜面でもスライダーの SV が変わらないようにします。**Scale to new timing** を使う場合は無効にすることをおすすめします。
* **Fix colourhax**: カラースキップを調整し、パターンと元の譜面でオブジェクトの色インデックスが変わらないようにします。
* **Fix slider tick rate**: パターン内の BPM を変更し、スライダーティックの間隔が変わらないようにします。

## パターンのコンテキストメニュー

ギャラリーのパターンを右クリックすると、次の操作ができます。

* **Properties**: 名前、作成日時、最終使用日時、使用回数など、パターンの詳細を表示します。
* **Delete**: 選択中のパターンを削除します。Shift キーを押すと確認ダイアログをスキップします。
* **Open in File Explorer**: 選択中のパターンのソースファイルをファイルエクスプローラーで開きます。
* **Group**: パターンをグループ化する操作を選択します。

## インポート設定

インポートボタンから、さまざまなソースのパターンをインポートできます。

* **Import Selected**: エディターで現在選択中のヒットオブジェクトからパターンを作成します。
  * **Name**: パターン名。
* **Import from .osu File**: コンピューター上の .osu ファイルからパターンをインポートします。
  * **Name**: パターン名。
  * **Pattern file path**: インポートするパターンファイルのパス。
  * **Filter**: .osu ファイルに適用するフィルター。
  * **Start Time**: パターンを開始する .osu ファイル内の時刻。
  * **End Time**: パターンを終了する .osu ファイル内の時刻。
* **Import from Code**: コードからパターンをインポートします。オンラインでパターンを共有する場合に便利です。
  * **Name**: パターン名。
  * **Hit Objects**: ヒットオブジェクトのコード。
  * **Timing Points**: タイミングポイントのコード。
  * **Global SV**: パターンのヒットオブジェクトに対するグローバルスライダー速度を設定します。
  * **Game Mode**: パターンのゲームモードを指定します。

## Project メニュー

Pattern Gallery の **Project** メニューでは、次の操作ができます。

* パターンコレクションを保存。
* パターンコレクションを読み込み。
* パターンコレクションの名前を変更。
* パターンコレクションをインポート。
* パターンコレクションをエクスポート。
