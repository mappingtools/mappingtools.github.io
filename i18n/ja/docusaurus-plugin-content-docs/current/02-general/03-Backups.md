Mapping Tools は、設定されたバックアップフォルダーに譜面のバックアップを保存します。**About > Open backups folder** からフォルダーを開くか、**Preferences** で保存先を変更できます。

ライブエディター状態の読み取りが設定されている場合は、エディターでまだ保存されていない最新の状態もバックアップに含まれます。設定されていない場合は、ディスク上でアクセスできる譜面ファイルがバックアップされます。

## 自動バックアップ {#automatic-backups}

有効にすると、ツールが譜面を変更する前に Mapping Tools がバックアップを作成します。これにより、ツールの操作を取り消したいときに復元ポイントを使えます。**Preferences** でバックアップフォルダーと保存数の上限を設定できます。上限に達すると、最も古いバックアップから削除されます。

## 定期バックアップ {#periodic-backups}

有効にすると、ライブエディター状態を読み取れる間、Mapping Tools は現在の譜面を定期的にバックアップします。前回から譜面に変更がなければ、バックアップは作成されません。定期バックアップのファイル名には `PB` が含まれます。

## 手動バックアップ {#manual-backups}

**File** メニューから Selected beatmap のバックアップを作成したり、譜面にバックアップを読み込んだりできます。手動バックアップのファイル名には `UB` が含まれます。**QuickUndo** は、定期バックアップ以外の最新のバックアップを osu! で現在開いている譜面に復元します。
