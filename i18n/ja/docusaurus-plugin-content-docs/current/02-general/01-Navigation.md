Mapping Tools を起動すると、既定で「はじめに」画面が開きます。この画面にはアプリケーションの変更履歴と、Mapping Tools で最近使った譜面の一覧が表示されます。この画面はナビゲーションメニューからも開けます。

画面上部の青いバーには、ナビゲーション切り替えボタン、メニュー、_Selected beatmap_ が表示されます。_Selected beatmap_ は、ほとんどのマッピングツールで作業対象となる譜面です。

ナビゲーション切り替えボタンを押すと左側にメニューが開き、Mapping Tools の各ページに移動できます。検索欄にページ名を入力し、`Enter` を押すと検索結果の先頭に移動できます。いつでも `Ctrl+K` でナビゲーションメニューを開けます。

### File {#file}

**File** メニューには、譜面ファイルの選択、読み込み、保存を行うボタンがあります。

- **Open beatmap** はファイルエクスプローラーを開き、1 つ以上の譜面を選択して Selected beatmap に設定します。
- **Open current beatmap** は、_osu!_ クライアントで現在選択されている譜面を Selected beatmap に設定します。
- **Generate backup** は、選択中の譜面のバックアップを作成します。
- **Load backup** はファイルエクスプローラーを開き、Selected beatmap に読み込むバックアップ譜面を選択できます。
- **QuickUndo** は、最新の定期バックアップ以外のバックアップを Selected beatmap に読み込みます。
- **BetterSave™ current beatmap** は、_osu!_ エディターで現在開いている譜面を、座標を切り捨てず丸めて保存します。

### About {#about}

**About** メニューには、Mapping Tools の追加情報や便利なリンクがあります。

- **Open backups folder** は、Mapping Tools が作成したすべてのバックアップがあるフォルダーを開きます。
- **Open Mapping Tools folder** は、設定、バックアップ、エクスポートなど Mapping Tools が作成したすべてのファイルがあるフォルダーを開きます。

### Project {#project}

**Project** メニューは、マッピングツールの画面を表示しているときだけ使えます。ツール固有の設定を保存、読み込みするボタンがあります。
