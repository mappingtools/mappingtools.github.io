Mapping Tools の主な開発は、次の 2 つの GitHub リポジトリで行われています。

### Mapping Tools

Mapping Tools のデスクトップアプリケーション本体です。

https://github.com/OliBomby/Mapping_Tools

### Mapping Tools Website

現在ご覧のウェブサイトです。Mapping Tools の情報をウェブで公開しています。

https://github.com/mappingtools/mappingtools.github.io

## 開発が終了したプロジェクト

これらのプロジェクトは現在積極的に開発されていませんが、今でも役立つ場合があります。

### Mapping Tools Core

.NET 開発者向けの Mapping Tools バックエンドパッケージです。他のプログラムから Mapping Tools の機能を利用できます。

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

Mapping Tools のウェブ版です。Mapping Tools Core を使用しており、完全なクロスプラットフォーム対応です。

https://github.com/misakura-rin/mapping-tools-web
