Mapping Tools は、osu! のマッピング用ツールを**ひとつのアプリケーション**にまとめたものです。
手作業では何時間もかかる譜面の変更をすばやく行えます。
バックアップやメモリ読み取りなど、すべてのツールで利用できる**便利な機能**も備えているため、いつでも手早く安心して作業できます。

![Mapping Tools のロゴ](/img/mt_banner.png)

## はじめに {#get-started}

**ガイド**または[**動画チュートリアル**](https://www.youtube.com/playlist?list=PLuijZnrwVA86pO7zIP9oVu-7YAQ5qEe2Y)を参考に、Mapping Tools の使い方をすぐに身につけましょう。

1. Mapping Tools を[**インストール**](02-installation.md)して起動します。
2. Mapping Tools を[**設定**](02-installation.md#setup)します。
3. **File > Open (current) beatmap** から譜面を選択します。
4. ナビゲーションメニューからツールを開きます: `Ctrl+K`
5. 設定を行い、右下の実行ボタンを押します。
6. 保存せずに譜面を再読み込みします: `Ctrl+L, Enter`

## 機能 {#features}

Mapping Tools は自由なマッピングを支援し、シンプルなツールの利便性を最大限に引き出します。

- **Map Cleaner**
  - 不要な緑線を削除
  - 緑線、ヒットオブジェクト、ブックマークを再スナップ
  - 未使用のヒットサウンドサンプルを削除
- **Metadata Manager**
  - マップセット全体のメタデータを一括編集
  - 重複するタグを削除
- **Property Transformer**
  - すべてのタイミングポイントまたはヒットオブジェクトの時間をずらす、または拡大縮小
  - 複数の緑線の音量、インデックス、スライダー速度を一括変更
- **Slider Merger**
  - 複数のスライダーや円を、形状を引き継いだひとつの大きなスライダーに結合
- **Slider Completionator**
  - スライダーの長さや時間を設定
  - 4 倍を超えるスライダー速度を実現
- **Timing Copier**
  - 譜面間でタイミングをコピー
  - 新しいタイミングに合わせてオブジェクトを自動的に再スナップ、拡大縮小
- **Timing Helper**
  - 複雑なタイミングをすばやく作成
- **Hitsound Copier**
  - 譜面間でヒットサウンドをコピー
  - ストーリーボード上のサンプルを、不足しているヒットサウンドの代わりにコピー
  - スライダーティックやスライダーのスライド音にヒットサウンドをコピー
  - スライダー終端の音を自動でミュート
- **Hitsound Studio**
  - [osu! mania のヒットサウンドを osu! standard 用に変換](../04-guides/hs-studio-convert-mania-to-standard.md)
  - 複数のマップセットにあるカスタムヒットサウンドをひとつに統合
  - MIDI をキーサウンドに変換
- **Hitsound Preview Helper**
  - 位置に基づいてオブジェクトにヒットサウンドを配置
  - Hitsound Studio と互換性のあるヒットサウンド譜面を簡単に作成
- **Rhythm Guide**
  - 譜面からリズムを抽出し、ヒットサウンド付けのガイドとして使用
- **Geometry Dashboard**
  - マッピング中に使える幾何学図形をエディター上にリアルタイム表示
- **Combo Colour Studio**
  - Colourhax を簡単に作成
  - 譜面間で Colourhax をコピー
- **Sliderator**
  - スライダーの途中で速度を変更
  - 加速または減速するストリームを作成
- **Auto-fail Detector**
  - 2B スタイルの譜面で Auto-fail を検出
  - Auto-fail を自動修正
- **Pattern Gallery**
  - マッピングパターンのコレクションを作成、共有
  - 譜面間でパターンをコピー
- **Mapset Merger**
  - 複数のマップセットをひとつに統合
- **Tumour Generator**
  - スライダーの両端にさまざまな形状を追加
  - 新しい方法でスライダー全体をデザイン
- **Slider Picturator**
  - 画像をスライダーに変換して譜面に配置
