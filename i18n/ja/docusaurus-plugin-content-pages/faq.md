# FAQ

## 譜面に変更が反映されません。なぜですか？

アプリケーション上部の青いバーにある **Selected Map** を確認し、正しい譜面のパスが設定されていることを確かめてください。

また、ツールの実行後は、保存せずにエディターを**再読み込み**してください。エディターで保存すると、古いバージョンの譜面で .osu ファイルが上書きされ、ツールによる変更が元に戻ってしまいます。エディターで `Ctrl+L` を押してから `Enter` を押すと、すばやく譜面を再読み込みできます。

## ツールの実行時に「Could not find part of the path」または「Empty path name is not legal」というエラーが出ます。

ウィンドウ上部の**譜面名**にマウスカーソルを合わせると、完全なパスが表示されます。そのパスは存在していますか？Songs フォルダーは正しい場所にありますか？Songs フォルダーが既定の AppData の場所にない場合は、**Preferences** で正しい Songs フォルダーのパスを設定してください。

## 特定の譜面でどのツールを実行しても毎回エラーになりますが、ほかの譜面ではエラーになりません。

編集しようとしている譜面が、古くてサポートされていないファイル形式を使っているか、破損している可能性があります。エディターで譜面を開いて保存すると修復できます。これにより osu! が譜面を Mapping Tools と互換性のある最新のファイル形式に更新します。

## ツールを使ったら譜面が壊れました。どうすればいいですか？

Mapping Tools は変更を行うたびに譜面のバックアップを保存します。**About > Open backup folder** からバックアップを確認できます。**File > Load backup** または **Preferences** で有効にできる QuickUndo ホットキーを使って、バックアップを Current Map に読み込むこともできます。

## 「Open Current Beatmap」が動作しない、または選択したヒットオブジェクトを取得できません。

これらの機能は osu! クライアントのメモリ読み取りに依存しています。メモリの読み取りが一時的に動作しなくなることがあり、その場合は osu! やコンピューターを再起動すると直ることがよくあります。ほかに考えられる原因と解決方法は次のとおりです。

- ファイアウォールやウイルス対策ソフトが Mapping Tools をブロックしている: ウイルス対策ソフトを無効にするか、Mapping Tools を例外に追加して再度お試しください。
- Mapping Tools が最新ではない: osu! の変更に対応するため、Mapping Tools の更新が必要な場合があります。
- osu! が最新ではない: プライベートサーバーから切り替え、osu! を最新バージョンに更新してください。
- osu! の更新でメモリオフセットが変更された: 修正できるよう、お知らせください。
- Windows 7 以前で Mapping Tools を使用している: .NET Framework 4.5.1 以降がインストールされていることを確認してください。
- Windows 以外の OS で Mapping Tools を使用している: [インストールガイド](/docs/mapping-tools/installation)をご覧ください。

## ヒットサウンドをコピーせずにスライダー終端の音をミュートするには？

スライダー終端だけをミュートするには、**Copy hitsounds from** 欄を空にし、**Copy hitsounds to** 欄に終端をミュートする譜面を追加してください。ヒットサウンドはコピーされませんが、スライダー終端のミュートは適用されます。

終端をミュートしながらヒットサウンドもコピーする場合、ツールはコピー元の譜面のオブジェクトを参照します。そのため、ヒットサウンドを追加した位置ではスライダー終端がミュートされません。スライダー終端のミュート機能が独立したツールではなく Hitsound Copier に含まれているのはこのためです。

## Mapping Tools の起動時に .NET のインストールを求められますが、すでにインストール済みです。

現在の Mapping Tools は .NET 10 を対象としており、自己完結型で配布されています。そのため、別途 .NET をインストールする必要はありません。

それでも .NET のインストールを求められる場合は、Mapping Tools の最新リリースを起動していることを確認し、ウェブサイトから新しいインストーラーをダウンロードして再インストールしてください。

## Mapping Tools は lazer で動作しますか？

はい、Mapping Tools のほとんどの機能は lazer で動作します。詳しくは[ガイド](/docs/guides/use-mt-in-lazer)をご覧ください。
