QuickRun ускоряет работу с Mapping Tools. Функция запускает инструмент по горячей клавише и автоматически перезагружает редактор. Таким образом, для применения инструмента достаточно одного нажатия.

QuickRun можно включить в разделе **Настройки**.

## Настройка {#setup}

Чтобы включить QuickRun, откройте **Настройки** и назначьте горячую клавишу в поле **Горячая клавиша QuickRun**. После этого она будет запускать инструмент, открытый в Mapping Tools.

Для этого подойдёт `Alt+M`: это сочетание не конфликтует со стандартными горячими клавишами редактора osu!.

Если включён параметр **Автоматически перезагружать после QuickRun**, после завершения работы инструмента Mapping Tools отправит команду перезагрузки редактору osu!. Тогда перезагружать карту вручную не придётся.

:::info
При запуске инструмента через QuickRun всегда используется карта, открытая в редакторе, а не карта, выбранная в Mapping Tools.
:::

## SmartQuickRun {#smartquickrun}

Поставьте флажок справа от поля горячей клавиши QuickRun, чтобы включить **SmartQuickRun**. Эта функция позволяет запускать разные инструменты в зависимости от количества объектов, выбранных в редакторе.

SmartQuickRun различает три случая:
- **Ничего**: не выбрано ни одного игрового объекта. `N=0`
- **Один**: выбран ровно один игровой объект. `N=1`
- **Несколько**: выбрано больше одного игрового объекта. `N>1`

## QuickUndo {#quickundo}

**QuickUndo** загружает в редактор последнюю резервную копию и тем самым отменяет предыдущий запуск инструмента. Как и QuickRun, она поддерживает **автоматическую перезагрузку**. Рекомендуется использовать QuickUndo вместе с QuickRun.

Для QuickUndo подойдёт сочетание `Ctrl+Shift+Z`.
