Mapping Tools хранит резервные копии карт в указанной папке. Откройте её через меню **О программе > Открыть папку резервных копий** или измените расположение папки в **Настройках**.

Если настроено чтение текущего состояния редактора, резервные копии могут включать последние несохранённые изменения. В противном случае Mapping Tools копирует файл карты, к которому есть доступ на диске.

## Автоматические резервные копии {#automatic-backups}

Если эта функция включена, Mapping Tools создаёт резервную копию перед изменением карты инструментом. Так можно будет восстановить исходную версию, если понадобится отменить запуск инструмента. В **Настройках** можно задать папку для копий и ограничение на их количество. Когда лимит достигнут, старые копии удаляются.

## Периодические резервные копии {#periodic-backups}

Если эта функция включена, Mapping Tools периодически сохраняет текущую карту, пока может считывать её состояние из редактора. Если карта не изменилась с момента предыдущей копии, новая не создаётся. В именах периодических копий есть `PB`.

## Ручные резервные копии {#manual-backups}

В меню **Файл** можно создать резервную копию выбранной карты или загрузить в неё уже существующую. В именах ручных копий есть `UB`. **QuickUndo** восстанавливает самую новую непериодическую копию в карте, открытой сейчас в osu!.
