Mapset Merger позволяет объединять несколько наборов карт в один большой набор.

Инструмент автоматически разрешает конфликты файлов: перемещает как можно больше файлов в отдельные подпапки и заново создаёт наборы сэмплов для пользовательских звуковых эффектов. К сожалению, объединить скины карт и пользовательские звуковые эффекты спиннеров нельзя: эти файлы не указаны явно в карте, поэтому они всегда влияют на весь набор.

## Добавление наборов карт {#adding-mapsets}

Нажмите кнопку с плюсом в правом нижнем углу, чтобы добавить набор карт. В него автоматически будут добавлены данные набора выбранной карты. Если нажать кнопку с плюсом, удерживая Shift, будет использован набор карт, открытый сейчас в клиенте osu!.

Все наборы карт, которые будут объединены, отображаются в списке. У каждого набора есть название и путь к корневой папке. По названию будут распределяться файлы объединённого набора, поэтому выбирайте уникальные и короткие названия. Чтобы изменить путь в списке, **дважды щёлкните** по нему. Рядом появится кнопка обзора, с помощью которой можно выбрать путь в проводнике.

## Экспорт {#exporting}

Нажмите кнопку запуска, чтобы объединить наборы карт и экспортировать файлы в папку, указанную в поле **Путь экспорта**. Эта папка должна существовать, иначе возникнет ошибка.

Если включён параметр **Переместить сториборд в .osu**, содержимое каждого файла .osb в наборе будет перенесено в файлы .osu. Сториборды станут отдельными для каждой карты, и их содержимое не будет переноситься на остальные наборы объединённой карты. Это удобно при объединении наборов с разными сторибордами. Однако учитывайте, что большой файл сториборда при нескольких сложностях многократно увеличит объём данных и размер файлов .osu.
