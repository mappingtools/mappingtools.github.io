Pattern Gallery позволяет импортировать и экспортировать паттерны из карт osu!, а также создавать коллекции паттернов, которыми можно делиться. Этот инструмент помогает быстро переносить любые группы игровых объектов или целые фрагменты карты между разными картами.

## Описание инструмента

С помощью Pattern Gallery можно:

* Импортировать и экспортировать паттерны из карт osu!, перенося любые группы игровых объектов между картами.
* Создавать коллекции паттернов, которыми можно делиться с друзьями.
* Добавлять и удалять паттерны кнопками в нижней части окна.
* Экспортировать паттерн в выбранную карту: выберите один или несколько паттернов и нажмите кнопку запуска либо дважды щёлкните по паттерну.
* Настраивать дополнительные параметры обработки паттерна во время экспорта.
* Сохранять, загружать, переименовывать, импортировать и экспортировать коллекции паттернов через меню **Проект**.

## Использование

1. Откройте Pattern Gallery в Mapping Tools.
2. Добавьте паттерны в коллекцию с помощью команд импорта.
3. Выберите паттерн в галерее.
4. Нажмите кнопку запуска, чтобы экспортировать паттерн в выбранную карту.

## Функции и настройки

Инструмент предоставляет следующие возможности:

* **Управление паттернами**: добавление, удаление, переименование и упорядочивание паттернов в коллекциях.
* **Параметры импорта**: импорт паттернов из разных источников, например выбранных объектов, файлов карт или кодов паттернов.
* **Параметры экспорта**: настройка экспорта паттернов, включая масштабирование, поворот и фильтрацию.

## Параметры экспорта

При экспорте паттерна можно изменить следующие параметры:

* **Смещение экспорта**: задаёт время, в которое будет помещён паттерн. Можно использовать исходное время паттерна, собственное время или текущее время редактора.
  * **Собственное смещение экспорта**: задаёт время для режима собственного смещения.
* **Запас при удалении**: дополнительное время в миллисекундах вокруг паттерна, в течение которого удаляются части исходной карты.
* **Минимальная длительность паузы**: минимальное количество долей в паузе, необходимое для разделения паттерна на части.
* **Делители доли**: введите через запятую любые делители доли. Например: `1/4, 1/12, 1/7, 4/5, 0.13435622499`.
* **Пользовательский масштаб**: изменяет размер паттерна с помощью указанного коэффициента.
* **Пользовательский поворот**: поворачивает паттерн по часовой стрелке на указанное количество градусов.
* **Режим перезаписи паттерна**: определяет, что делать с перекрывающимися объектами паттерна и целевой карты. Доступны режимы:
  * **NoOverwrite**: сохраняет все существующие объекты карты и добавляет паттерн, ничего не удаляя.
  * **PartitionedOverwrite**: удаляет объекты исходной карты только в тех частях, где паттерн плотный.
  * **CompleteOverwrite**: удаляет все объекты исходной карты между началом и концом паттерна.
* **Режим перезаписи тайминга**: задаёт, как объединять тайминг исходной карты и паттерна.
* **Добавить звуковые эффекты**: экспортирует паттерн вместе со звуковыми эффектами его тайминговых точек.
* **Добавить kiai**: экспортирует паттерн вместе с эффектом kiai.
* **Масштабировать под новый размер круга**: изменяет масштаб паттерна так, чтобы расстояния относительно размера круга остались прежними.
* **Масштабировать под новый тайминг**: изменяет время паттерна так, чтобы расстояния в долях между объектами соответствовали новому таймингу. При наличии неснапнутых красных линий возможны неточные привязки. Не используйте этот параметр, если есть красные линии с BPM 0 или бесконечным BPM.
* **Привязать к новому таймингу**: привязывает объекты паттерна к новому таймингу с помощью указанных делителей доли.
* **Собрать объекты в стаки вручную**: вручную упорядочивает объекты паттерна в стаки.
* **Исправить глобальную SV**: меняет SV зелёных линий паттерна под глобальную SV новой карты, чтобы SV слайдеров осталась прежней.
* **Исправить SV под BPM**: меняет SV зелёных линий паттерна под новый BPM, чтобы SV слайдеров осталась прежней. Если включён параметр «Масштабировать под новый тайминг», эту функцию рекомендуется отключить.
* **Исправить colorhax**: меняет пропуск цвета так, чтобы индексы цветов объектов в паттерне и исходной карте совпадали.
* **Исправить частоту тиков слайдера**: изменяет BPM паттерна так, чтобы частота тиков слайдера осталась прежней.

## Контекстное меню паттерна

Щёлкните правой кнопкой мыши по паттерну в галерее, чтобы открыть контекстное меню со следующими командами:

* **Свойства**: показывает сведения о паттерне, например название, время создания, время последнего использования и количество использований.
* **Удалить**: удаляет выбранные паттерны. Удерживайте Shift, чтобы пропустить подтверждение.
* **Открыть в проводнике**: открывает исходные файлы выбранных паттернов в проводнике.
* **Сгруппировать**: команды группировки паттернов.

## Параметры импорта

Кнопка импорта позволяет импортировать паттерны из разных источников.

* **Импортировать выбранные**: создаёт паттерн из выбранных в редакторе игровых объектов.
  * **Название**: название паттерна.
* **Импортировать из файла .osu**: импортирует паттерны из файла .osu на диске.
  * **Название**: название паттерна.
  * **Путь к файлу паттерна**: путь к импортируемому файлу паттерна.
  * **Фильтр**: фильтр для файла .osu.
  * **Начальное время**: время в файле .osu, с которого начинается паттерн.
  * **Конечное время**: время в файле .osu, на котором заканчивается паттерн.
* **Импортировать из кода**: импортирует паттерн из кода. Этот способ удобен, если вы делитесь паттернами в интернете.
  * **Название**: название паттерна.
  * **Игровые объекты**: код игровых объектов.
  * **Тайминговые точки**: код тайминговых точек.
  * **Глобальная SV**: глобальная скорость слайдеров для игровых объектов паттерна.
  * **Режим игры**: режим игры, для которого предназначен паттерн.

## Меню проекта

В меню **Проект** инструмента Pattern Gallery можно:

* Сохранять коллекции паттернов.
* Загружать коллекции паттернов.
* Переименовывать коллекции паттернов.
* Импортировать коллекции паттернов.
* Экспортировать коллекции паттернов.
