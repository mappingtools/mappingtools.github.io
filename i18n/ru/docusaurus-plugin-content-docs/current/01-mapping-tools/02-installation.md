У Mapping Tools есть нативные версии для **Windows, Linux и macOS**. Скачайте сборку для своего процессора на [странице загрузки](/download) или в разделе [выпусков GitHub](https://github.com/OliBomby/Mapping_Tools/releases/latest).

Все пакеты автономны и включают среду выполнения .NET 10.

## Выбор пакета

- **Windows**: используйте установщик или портативный ZIP-архив. Для большинства систем подойдёт x64; x86 предназначен для 32-разрядной Windows.
- **Linux**: используйте AppImage или портативный ZIP-архив для x64 или ARM64.
- **macOS**: скачайте портативный ZIP-архив для Intel (x64) или Apple silicon (ARM64), затем откройте **Mapping Tools.app** в распакованной папке.

- **osu! stable**: в Windows для определения текущей карты и чтения состояния редактора используется интеграция с памятью процесса, а для автоперезагрузки имитируются нажатия клавиш. В Linux и macOS запустите stable через Wine и включите совместимый API **Gosumemory/Tosu** по адресу `127.0.0.1:24050`, чтобы определять текущую карту. В настройках укажите **папку Songs**.
- **osu! lazer**: выберите **Файл > Редактировать во внешнем редакторе**, чтобы открыть файлы карты. Mapping Tools автоматически определит карту, открытую для внешнего редактирования; в таблице это считается определением текущей карты. Чтобы применить изменения, выберите в lazer **Завершить редактирование и импортировать изменения**. См. [руководство по lazer](/docs/guides/use-mt-in-lazer).
- **osu! unstable**: для получения текущей карты, чтения состояния редактора в реальном времени и перезагрузки редактора выберите **MTIPC** в настройках. Для этих функций требуется сервер MTIPC в клиенте. Чтение состояния редактора и перезагрузка редактора в Linux и macOS по умолчанию отключены.
- **Глобальные горячие клавиши**: в Linux поддержка зависит от X11 или рабочего стола с порталом глобальных сочетаний клавиш. В macOS предоставьте запрошенные системой разрешения на доступ к клавиатуре.

Карту всегда можно выбрать вручную через **Файл > Открыть карту**.

## Настройка {#setup}

После установки Mapping Tools откройте меню навигации кнопкой в левом верхнем углу и перейдите в **Настройки**, чтобы настроить приложение.

В первую очередь задайте следующие параметры:

- **Папка osu!**: путь к папке, в которой находится _osu!_.
- **Папка Songs**: путь к папке со всеми вашими картами. Обычно она находится прямо в папке _osu!_.
- **Файл конфигурации пользователя osu!**: путь к файлу пользовательских настроек osu!. Обычно он находится прямо в папке _osu!_ и называется `osu.[username].cfg`.

:::note

Если вы используете osu!stable, проверьте правильность этих путей: иначе Mapping Tools может работать некорректно.

:::
