У Mapping Tools есть нативные версии для **Windows, Linux и macOS**. Скачайте сборку для своего процессора на [странице загрузки](/download) или в разделе [выпусков GitHub](https://github.com/OliBomby/Mapping_Tools/releases/latest).

Все пакеты автономны и включают среду выполнения .NET 10.

## Выбор пакета

- **Windows**: используйте установщик или портативный ZIP-архив. Для большинства систем подойдёт x64; x86 предназначен для 32-разрядной Windows.
- **Linux**: используйте AppImage или портативный ZIP-архив для x64 или ARM64.
- **macOS**: скачайте портативный ZIP-архив для Intel (x64) или Apple silicon (ARM64), затем откройте **Mapping Tools.app** в распакованной папке.

## Интеграция с редактором на разных платформах

Инструменты для работы с файлами карт работают во всех версиях приложения. Некоторые функции, связанные с открытым редактором, зависят от операционной системы и способа интеграции:

- **Geometry Dashboard** и чтение памяти через **Editor Reader** требуют Windows.
- В Linux и macOS поиск текущей карты по умолчанию использует локальный API **Gosumemory/Tosu** по адресу `127.0.0.1:24050`. Запустите совместимый API, чтобы воспользоваться командой **Открыть текущую карту**. На этих платформах чтение состояния редактора и автоматическая перезагрузка редактора по умолчанию отключены.
- Вы всегда можете выбрать карту напрямую через **Файл > Открыть карту**.

Для osu! lazer используйте команду **Файл > Редактировать во внешнем редакторе**. Подробнее см. в [руководстве по lazer](/docs/guides/use-mt-in-lazer).

## Настройка {#setup}

После установки Mapping Tools откройте меню навигации кнопкой в левом верхнем углу и перейдите в **Настройки**, чтобы настроить приложение.

В первую очередь задайте следующие параметры:

- **Папка osu!**: путь к папке, в которой находится _osu!_.
- **Папка Songs**: путь к папке со всеми вашими картами. Обычно она находится прямо в папке _osu!_.
- **Файл конфигурации пользователя osu!**: путь к файлу пользовательских настроек osu!. Обычно он находится прямо в папке _osu!_ и называется `osu.[username].cfg`.

:::note

Если вы используете osu!stable, проверьте правильность этих путей: иначе Mapping Tools может работать некорректно.

:::
