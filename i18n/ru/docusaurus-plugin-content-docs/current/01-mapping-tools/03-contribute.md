Основная разработка Mapping Tools ведётся в двух репозиториях на GitHub:

### Mapping Tools

Основное настольное приложение Mapping Tools.

https://github.com/OliBomby/Mapping_Tools

### Сайт Mapping Tools

Вы находитесь на сайте, который знакомит пользователей по всему миру с Mapping Tools.

https://github.com/mappingtools/mappingtools.github.io

## Устаревшие проекты

Эти проекты больше не развиваются активно, но всё ещё могут быть полезны.

### Mapping Tools Core

Серверный пакет Mapping Tools для разработчиков .NET. Позволяет использовать функции Mapping Tools в других программах.

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

Веб-версия Mapping Tools. Она использует Mapping Tools Core и полностью совместима с разными платформами.

https://github.com/misakura-rin/mapping-tools-web
