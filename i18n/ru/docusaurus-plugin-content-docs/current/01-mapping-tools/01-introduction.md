Mapping Tools объединяет инструменты для создания карт osu! в **одном приложении**.
С его помощью можно быстро вносить изменения в карту, на которые вручную ушли бы часы.
Все инструменты используют общие **функции для удобства работы**, например резервное копирование и чтение памяти игры, поэтому они всегда под рукой и работают надёжно.

![Логотип Mapping Tools](/img/mt_banner.png)

## Начало работы {#get-started}

Быстро познакомьтесь с Mapping Tools: воспользуйтесь одним из **руководств** или [**видеоуроками**](https://www.youtube.com/playlist?list=PLuijZnrwVA86pO7zIP9oVu-7YAQ5qEe2Y).

1. [**Установите**](02-installation.md) и запустите Mapping Tools.

2. [**Настройте**](02-installation.md#setup) Mapping Tools.

3. Выберите карту с помощью команды **Файл > Открыть текущую карту**.

4. Перейдите к нужному инструменту через меню навигации: `Ctrl+K`.

5. Настройте инструмент и запустите его кнопкой в правом нижнем углу.

6. Перезагрузите карту в редакторе без сохранения: `Ctrl+L`, затем `Enter`.

## Возможности {#features}

Mapping Tools создан с упором на свободу действий и стремится сделать простые инструменты как можно полезнее.

- **Map Cleaner**
  - Удаление бесполезных зелёных линий
  - Переснап зелёных линий, объектов и закладок
  - Удаление неиспользуемых сэмплов звуковых эффектов
- **Metadata Manager**
  - Редактирование метаданных всего набора карт за раз
  - Удаление повторяющихся тегов
- **Property Transformer**
  - Смещение или масштабирование тайминговых точек и объектов
  - Изменение громкости, индекса или скорости слайдеров сразу у нескольких зелёных линий
- **Slider Merger**
  - Объединение нескольких слайдеров и кругов в один большой слайдер с общей формой
- **Slider Completionator**
  - Настройка длительности или длины слайдеров
  - Увеличение скорости слайдеров выше 4x
- **Timing Copier**
  - Копирование тайминга между картами
  - Автоматический переснап и масштабирование объектов под новый тайминг
- **Timing Helper**
  - Более быстрое создание сложного тайминга
- **Hitsound Copier**
  - Копирование звуковых эффектов между картами
  - Использование сэмплов из сториборда вместо отсутствующих звуковых эффектов
  - Копирование звуковых эффектов на тики и звуки скольжения слайдеров
  - Автоматическое приглушение концов слайдеров
- **Hitsound Studio**
  - [Преобразование звуковых эффектов osu!mania в звуковые эффекты osu!standard](../04-guides/hs-studio-convert-mania-to-standard.md)
  - Объединение пользовательских звуковых эффектов из нескольких наборов карт в один
  - Преобразование MIDI в клавишные звуки
- **Hitsound Preview Helper**
  - Размещение звуковых эффектов на объектах в зависимости от их положения
  - Простое создание карт звуковых эффектов, совместимых с Hitsound Studio
- **Rhythm Guide**
  - Извлечение ритма из карт в качестве ориентира при расстановке звуковых эффектов
- **Geometry Dashboard**
  - Отображение геометрических направляющих поверх редактора для создания карт
- **Combo Colour Studio**
  - Простое создание colorhax
  - Копирование colorhax между картами
- **Sliderator**
  - Изменение скорости слайдера на его протяжении
  - Создание ускоряющихся и замедляющихся стримов
- **Auto-fail Detector**
  - Обнаружение автофейла в картах в стиле 2B
  - Автоматическое исправление автофейла
- **Pattern Gallery**
  - Создание и публикация коллекций паттернов для карт
  - Копирование паттернов между картами
- **Mapset Merger**
  - Объединение нескольких наборов карт в один
- **Tumour Generator**
  - Добавление разных форм вдоль краёв слайдеров
  - Новый способ проектировать слайдеры целиком
- **Slider Picturator**
  - Преобразование изображения в слайдер и добавление его на карту
