В osu!mania несколько нот могут приходиться на один тик. Это даёт больше свободы при расстановке звуковых эффектов: можно одновременно использовать несколько наборов сэмплов или пользовательских сэмплов. Из-за этого звуковые эффекты из osu!mania сложнее скопировать в osu!standard, где на один тик может приходиться не больше одной ноты. Hitsound Studio позволяет преобразовать звуковые эффекты osu!mania в osu!standard и открыть больше возможностей для работы со звуком.

## Шаг 1. Настройка Hitsound Studio {#1}

Откройте Hitsound Studio в Mapping Tools. В меню **Проект** выберите **Новый проект**. Если не хотите потерять текущие настройки Hitsound Studio, сначала сохраните их с помощью команды **Сохранить проект**.

## Шаг 2. Импорт слоёв звуковых эффектов {#2}

Нажмите кнопку с плюсом в правом нижнем углу окна, чтобы открыть окно импорта. Перейдите на вкладку **Импортировать звуковые эффекты**, чтобы импортировать все звуковые эффекты из карты. В поле **Исходная карта** выберите карту со звуковыми эффектами osu!mania, которые нужно преобразовать. Установите флажки **Найти повторяющиеся сэмплы** и **Удалить повторяющиеся звуковые эффекты**. Если на карте используются сэмплы из сториборда для заполнения пропусков в звуковых эффектах, также установите флажок **Добавить сэмплы из сториборда**. Затем нажмите **Принять**. В Hitsound Studio появится список слоёв звуковых эффектов.

## Шаг 3. Настройка {#3}

В нижней части окна нужно задать ещё два параметра: **Базовая карта** и **Сэмпл по умолчанию**. Выберите карту, которую хотите преобразовать, в поле базовой карты. Из неё будут взяты метаданные, тайминг и уровни громкости.

Для сэмпла по умолчанию доступно несколько вариантов. Выберите подходящий. Этот сэмпл будет использоваться, если в слоях не задан обычный hitnormal, а osu!standard всегда воспроизводит обычный hitnormal. Можно оставить поле пустым, выбрать **Набор сэмплов Soft** и указать громкость `-1`.

## Шаг 4. Экспорт {#4}

Нажмите кнопку запуска в правом нижнем углу окна. Откроется диалог с параметрами экспорта. Убедитесь, что в полях **Режим экспорта** и **Экспортируемый режим игры** выбрано **Standard**. Также можно выбрать **Vorbis (.ogg)** для параметров **Формат файлов сэмплов** и **Формат смешанных файлов сэмплов**. Тогда все сэмплы будут преобразованы в `.ogg`, что уменьшит размер файлов. Нажмите **Принять**, чтобы начать экспорт звуковых эффектов.

Когда экспорт завершится, откроется папка экспорта. В ней будут файл `.osu` с изменениями звуковых эффектов osu!standard и несколько необходимых аудиофайлов. Скопируйте все эти файлы в набор карт osu!standard, а затем скопируйте звуковые эффекты из изменённой карты с помощью Hitsound Copier.
