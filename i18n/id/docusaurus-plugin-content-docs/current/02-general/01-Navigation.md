Secara default, Mapping Tools terbuka di layar Mulai, yang berisi changelog aplikasi serta daftar peta yang baru-baru ini digunakan dengan Mapping Tools. Layar ini juga dapat dibuka melalui menu navigasi.

Di bagian atas layar terdapat bilah biru berisi tombol navigasi, menu, dan tampilan **Selected beatmap**. Beatmap inilah yang akan digunakan oleh sebagian besar alat Mapping Tools.

Tombol navigasi membuka menu di sebelah kiri untuk berpindah ke semua halaman Mapping Tools. Di sana terdapat kolom pencarian untuk mengetik nama halaman. Tekan `Enter` untuk membuka hasil teratas. Kamu juga dapat menekan `Ctrl+K` kapan saja untuk membuka menu navigasi.

### File {#file}

Menu **File** berisi tombol untuk memilih, memuat, dan menyimpan file beatmap.

- **Open beatmap** membuka file explorer untuk memilih satu atau beberapa beatmap sebagai beatmap yang dipilih.
- **Open current beatmap** menetapkan beatmap yang sedang dipilih di klien _osu!_ sebagai beatmap yang dipilih.
- **Generate backup** membuat cadangan beatmap yang dipilih.
- **Load backup** membuka file explorer untuk memilih cadangan beatmap yang akan dimuat ke beatmap yang dipilih.
- **QuickUndo** memuat cadangan nonperiodik terbaru ke beatmap yang dipilih.
- **BetterSave™ current beatmap** menyimpan beatmap yang sedang terbuka di editor _osu!_ dengan membulatkan koordinat, bukan memotongnya.

### About {#about}

Menu **About** menyediakan informasi tambahan dan tautan yang berguna untuk Mapping Tools.

- **Open backups folder** membuka folder berisi semua cadangan yang dibuat Mapping Tools.
- **Open Mapping Tools folder** membuka folder berisi semua file yang dibuat Mapping Tools, seperti pengaturan, cadangan, dan ekspor.

### Project {#project}

Menu **Project** hanya terlihat saat membuka layar salah satu alat mapping. Menu ini berisi tombol untuk menyimpan dan memuat pengaturan khusus alat tersebut.
