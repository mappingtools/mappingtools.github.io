Pengembangan utama Mapping Tools berlangsung di dua repositori GitHub berikut:

### Mapping Tools

Aplikasi desktop utama Mapping Tools.

https://github.com/OliBomby/Mapping_Tools

### Situs Mapping Tools

Situs web yang sedang kamu kunjungi. Situs ini membagikan pengetahuan tentang Mapping Tools kepada semua orang.

https://github.com/mappingtools/mappingtools.github.io

## Proyek yang tidak lagi aktif

Proyek-proyek ini tidak lagi dikembangkan secara aktif, tetapi mungkin masih berguna.

### Mapping Tools Core

Paket back-end Mapping Tools untuk pengembang .NET. Memungkinkan program lain menggunakan fitur Mapping Tools.

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

Versi web Mapping Tools. Menggunakan Mapping Tools Core dan sepenuhnya kompatibel lintas platform.

https://github.com/misakura-rin/mapping-tools-web
