Mapping Tools 的主要开发工作在以下两个 GitHub 仓库中进行：

### Mapping Tools

Mapping Tools 的桌面应用程序。

https://github.com/OliBomby/Mapping_Tools

### Mapping Tools Website

你正在浏览的网站。它通过互联网向大家分享 Mapping Tools 的相关知识。

https://github.com/mappingtools/mappingtools.github.io

## 已弃用的项目

这些项目已不再积极开发，但可能仍有用途。

### Mapping Tools Core

面向 .NET 开发者的 Mapping Tools 后端程序包。其他程序可以借此使用 Mapping Tools 的功能。

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

Mapping Tools 的网页版。它使用 Mapping Tools Core，完全兼容跨平台使用。

https://github.com/misakura-rin/mapping-tools-web
