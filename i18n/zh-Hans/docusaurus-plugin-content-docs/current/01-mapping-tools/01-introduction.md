Mapping Tools 将各种 osu! 谱面创作工具整合到**一个应用程序**中。
你可以快速修改谱面，而这些操作通常需要花数小时手动完成。
所有工具都可以使用备份、内存读取等**便捷功能**，因此你始终可以快速、可靠地完成工作。

![Mapping Tools Logo](/img/mt_banner.png)

## 开始使用 {#get-started}

阅读任意一篇**指南**或观看[**视频教程**](https://www.youtube.com/playlist?list=PLuijZnrwVA86pO7zIP9oVu-7YAQ5qEe2Y)，快速了解 Mapping Tools。

1. [**安装**](02-installation.md)并启动 Mapping Tools。
2. [**配置**](02-installation.md#setup) Mapping Tools。
3. 选择谱面：**File > Open (current) beatmap**。
4. 使用导航菜单打开工具：`Ctrl+K`。
5. 配置工具，然后点击右下角的运行按钮。
6. 不保存并重新载入谱面：`Ctrl+L, Enter`。

## 功能 {#features}

Mapping Tools 以自由创作为宗旨，充分发挥简单工具的实用价值。

- **Map Cleaner**
  - 移除无用的绿色时间点
  - 重新对齐绿色时间点、打击物件和书签
  - 移除未使用的打击音采样
- **Metadata Manager**
  - 一次编辑整个谱面集的元数据
  - 移除重复标签
- **Property Transformer**
  - 偏移或缩放所有时间点或打击物件的时间
  - 一次转换多个绿色时间点的音量、索引或滑条速度
- **Slider Merger**
  - 将多个滑条和圆圈合并为一个形状组合后的大型滑条
- **Slider Completionator**
  - 设置滑条的持续时间或长度
  - 实现高于 4 倍的滑条速度
- **Timing Copier**
  - 在谱面之间复制时间设置
  - 自动根据新时间重新对齐并缩放物件
- **Timing Helper**
  - 更快地创建复杂时间设置
- **Hitsound Copier**
  - 在谱面之间复制打击音
  - 使用故事板采样替代缺失的打击音
  - 将打击音复制到滑条打击点和滑动音效
  - 自动静音滑条尾音
- **Hitsound Studio**
  - [将 osu!mania 打击音转换为 osu!standard 打击音](../04-guides/hs-studio-convert-mania-to-standard.md)
  - 将多个谱面集中的自定义打击音合并到一个谱面集中
  - 将 MIDI 转换为按键音
- **Hitsound Preview Helper**
  - 根据物件位置放置打击音
  - 轻松创建与 Hitsound Studio 兼容的打击音谱面
- **Rhythm Guide**
  - 提取谱面的节奏，作为打击音制作参考
- **Geometry Dashboard**
  - 在编辑器上实时叠加几何图形，辅助谱面创作
- **Combo Colour Studio**
  - 轻松创建颜色变化效果
  - 在谱面之间复制颜色变化效果
- **Sliderator**
  - 在滑条中途改变滑条速度
  - 创建加速或减速的连打串
- **Auto-fail Detector**
  - 检测 2B 风格谱面中的自动失败
  - 自动修复自动失败
- **Pattern Gallery**
  - 创建并分享谱面模式合集
  - 在谱面之间复制模式
- **Mapset Merger**
  - 将多个谱面集合并为一个大型谱面集
- **Tumour Generator**
  - 沿滑条边缘添加各种形状
  - 用全新方式设计完整滑条
- **Slider Picturator**
  - 将图像转换为滑条并放入谱面
