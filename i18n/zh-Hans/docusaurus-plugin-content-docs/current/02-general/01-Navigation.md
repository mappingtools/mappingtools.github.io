Mapping Tools 默认会打开 Get Started Screen，其中包含应用程序的更新日志，以及最近使用 Mapping Tools 编辑过的谱面列表。你也可以通过导航菜单打开此页面。

屏幕顶部的蓝色栏包含导航菜单切换按钮、菜单和 _Selected beatmap_（已选谱面）的信息。大多数 Mapping Tools 工具都会处理这张谱面。

点击导航菜单切换按钮即可打开左侧菜单，从中前往 Mapping Tools 的各个页面。菜单中有搜索栏，输入页面名称后按 `Enter` 即可前往第一个搜索结果。你随时都可以按 `Ctrl+K` 打开导航菜单。

### File {#file}

**File** 菜单包含用于选择、载入和保存谱面文件的按钮。

- **Open beatmap** 打开文件资源管理器，以选择一张或多张谱面作为已选谱面。
- **Open current beatmap** 将已选谱面设为当前 _osu!_ 客户端中打开的谱面。
- **Generate backup** 为已选谱面创建备份。
- **Load backup** 打开文件资源管理器，以选择要载入已选谱面的备份谱面。
- **QuickUndo** 将最新的非周期性备份载入已选谱面。
- **BetterSave™ current beatmap** 保存 _osu!_ 编辑器中当前打开的谱面，并对坐标进行四舍五入，而不是截断。

### About {#about}

**About** 菜单提供有关 Mapping Tools 的更多信息和实用链接。

- **Open backups folder** 打开 Mapping Tools 所创建的备份所在文件夹。
- **Open Mapping Tools folder** 打开 Mapping Tools 创建的所有文件所在文件夹，例如设置、备份和导出文件。

### Project {#project}

只有在查看某个 Mapping Tools 工具页面时，才会显示 **Project** 菜单。此菜单提供用于保存和载入工具专属设置的按钮。
