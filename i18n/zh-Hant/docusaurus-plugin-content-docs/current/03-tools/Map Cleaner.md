Map Cleaner 會清除已選取譜面中的無用綠線，也能在整張譜面上執行其他實用操作。

Map Cleaner 會重建所有時間點：先記錄各時間點的影響，再以有條理的方式重新建立。因此，綠線會自動重新對齊使用它們的物件，並移除不必要的變更。除非啟用了其他功能，否則此流程不會改變譜面與打擊音效；你只會在編輯器中注意到差異。

## 譜面資訊設定 {#map-info-settings}

這些設定會影響 Map Cleaner 是否移除時間點中的項目。若要採取最保守的設定，可以全部勾選，這樣移除的內容最少。

- **Map uses volume changes in sliders**：勾選後，Map Cleaner 會知道滑條本體期間的音量變更是*刻意設定*的，因此不會移除。
- **Map uses sampleset changes in sliders**：勾選後，Map Cleaner 會知道滑條本體期間的音效組或音效索引變更是*刻意設定*的，因此不會移除。
- **Map uses volume changes in spinners**：勾選後，Map Cleaner 會知道轉盤期間的音量變更是*刻意設定*的，因此不會移除。

## 額外功能 {#additional-features}

除了正常的清理流程外，Map Cleaner 也能執行以下操作。

- **Resnap objects**：清理譜面時，重新對齊所有打擊物件與滑條尾端，並使用指定的拍點細分設定。
- **Resnap bookmarks**：使用預設的重新對齊方法調整所有書籤。如果書籤使用非一般的拍點細分，建議取消勾選此選項。
- **Remove unused samples**：移除譜面組中所有譜面與故事板都未使用的音訊樣本。可套用譜面外觀的樣本不受影響。
- **Remove muting**：移除音量為 5% 的打擊音效上的所有音量變更與自訂索引變更。如果某個時間點的音量為 5%，也會移除該時間點上的音量變更與自訂索引變更。
- **Mute unclickable hitsounds**：將所有來自不需要玩家主動操作的打擊物件事件設為 5% 音量。只有圓圈、滑條起點與長按音符起點會有聲音。這有助於理解譜面的節奏或遊玩方式。

## 重新對齊

重新對齊時，系統會將物件吸附至時間軸上最近的刻度，再向下取整為整數。如果打擊物件時間點後 10 毫秒內有紅線，則會改為吸附至該紅線，避免物件被重新對齊到紅線前 3 毫秒的刻度。

重新對齊滑條尾端有兩種方法。第一種會取得滑條的持續時間，再將其改為最接近的拍點細分倍數。這與在 osu! 原版編輯器中對滑條使用 `Ctrl+Shift+S` 類似。

只有當滑條中途或滑條結束後 20 毫秒內有紅線時，才會使用第二種方法。系統會依據新時間設定，將滑條結束時間吸附至最近的刻度。請注意，這會產生持續時間為整數的滑條；受時間軸刻度取整影響，實際長度會有所偏差。

所有轉盤結束時間與長按音符結束時間也會使用第二種方法重新對齊。

如果已選取的譜面使用 osu!mania 遊戲模式，重新對齊時也會將音符的 X 座標移至欄位中央，並將 Y 座標設為 192。

## 時間軸

每次執行 Map Cleaner 時，都會顯示簡易時間軸，標示程式對時間點所做的變更。

- 紅線代表已移除的時間點。
- 橘線代表已變更的時間點。
- 綠線代表新增的時間點。

若只是移動時間點，原本位置會顯示紅線，新位置則會顯示綠線。

你可以在時間軸上的任一條線上**按兩下**，前往編輯器中的對應時間。
