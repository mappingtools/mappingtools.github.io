Mapping Tools 預設會開啟「開始使用」畫面，其中顯示應用程式的更新日誌，以及最近在 Mapping Tools 中使用的譜面清單。你也可以從導覽選單開啟此畫面。

畫面頂端的藍色列包含導覽切換按鈕、選單，以及_已選取譜面_的資訊。大多數製圖工具會以此譜面進行操作。

按下導覽切換按鈕，左側便會開啟選單，可用來前往 Mapping Tools 的所有頁面。你可以在搜尋列輸入頁面名稱，並按下 `Enter` 前往最上方的搜尋結果。任何時候都能使用 `Ctrl+K` 開啟導覽選單。

### File {#file}

**File** 選單包含選取、載入與儲存譜面檔案的按鈕。

- **Open beatmap** 會開啟檔案總管，讓你選取一或多張譜面做為已選取譜面。
- **Open current beatmap** 會將已選取譜面設為 _osu!_ 用戶端目前選取的譜面。
- **Generate backup** 會建立已選取譜面的備份。
- **Load backup** 會開啟檔案總管，讓你選取要載入至已選取譜面的備份譜面。
- **QuickUndo** 會將最新的非定期備份載入已選取譜面。
- **BetterSave™ current beatmap** 會儲存目前在 _osu!_ 編輯器中開啟的譜面，並四捨五入座標，而不是截去小數。

### About {#about}

**About** 選單提供 Mapping Tools 的其他資訊與實用連結。

- **Open backups folder** 會開啟 Mapping Tools 建立的所有備份所在資料夾。
- **Open Mapping Tools folder** 會開啟存放 Mapping Tools 所建立檔案的資料夾，例如設定、備份與匯出檔案。

### Project {#project}

只有在檢視某個製圖工具的畫面時，才會顯示 **Project** 選單。此選單包含儲存與載入該工具專用設定的按鈕。
