Mapping Tools 的主要開發工作在以下兩個 GitHub 儲存庫進行：

### Mapping Tools

Mapping Tools 的主要桌面應用程式。

https://github.com/OliBomby/Mapping_Tools

### Mapping Tools 網站

你目前造訪的網站，透過網際網路與大家分享 Mapping Tools 的相關資訊。

https://github.com/mappingtools/mappingtools.github.io

## 已停止維護的專案

這些專案目前已停止積極開發，但可能仍有用途。

### Mapping Tools Core

提供給 .NET 開發者使用的 Mapping Tools 後端套件，讓其他程式也能使用 Mapping Tools 的功能。

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

Mapping Tools 的網頁版，使用 Mapping Tools Core，並完全支援跨平台。

https://github.com/misakura-rin/mapping-tools-web
