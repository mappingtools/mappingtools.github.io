Mapping Tools 將各種 osu! 製圖工具整合在**同一個應用程式**中。
它能快速修改譜面，省下原本可能需要數小時手動完成的工作。
所有工具共用**便利功能**，例如備份與讀取記憶體，因此你隨時都能使用快速可靠的工具。

![Mapping Tools 標誌](/img/mt_banner.png)

## 開始使用 {#get-started}

你可以閱讀任一篇**指南**或觀看[**影片教學**](https://www.youtube.com/playlist?list=PLuijZnrwVA86pO7zIP9oVu-7YAQ5qEe2Y)，快速認識 Mapping Tools。

1. [**安裝**](02-installation.md)並啟動 Mapping Tools。
2. [**設定**](02-installation.md#setup) Mapping Tools。
3. 使用 **File > Open (current) beatmap** 選取譜面。
4. 使用導覽選單前往工具：`Ctrl+K`
5. 設定工具，然後按右下角的執行按鈕。
6. 不儲存並重新載入譜面：`Ctrl+L, Enter`

## 功能 {#features}

Mapping Tools 以自由為核心，盡可能發揮簡單工具的效用。

- **Map Cleaner**
  - 移除無用的綠線
  - 重新對齊綠線、打擊物件與書籤
  - 移除未使用的打擊音效樣本
- **Metadata Manager**
  - 一次編輯整個譜面組的中繼資料
  - 移除重複標籤
- **Property Transformer**
  - 偏移或縮放所有時間點或打擊物件的時間
  - 一次轉換多條綠線的音量、索引或滑條速度
- **Slider Merger**
  - 將多個滑條與圓圈合併成一個形狀相接的大型滑條
- **Slider Completionator**
  - 設定滑條的持續時間或長度
  - 將滑條速度提高至 4 倍以上
- **Timing Copier**
  - 在譜面之間複製時間設定
  - 自動依新時間重新對齊並縮放物件
- **Timing Helper**
  - 更快速地建立複雜時間設定
- **Hitsound Copier**
  - 在譜面之間複製打擊音效
  - 使用故事板樣本補上缺少的打擊音效
  - 將打擊音效複製到滑條刻度與滑條滑動音效
  - 自動將滑條尾端靜音
- **Hitsound Studio**
  - [將 osu!mania 打擊音效轉換為 osu!standard 打擊音效](../04-guides/hs-studio-convert-mania-to-standard.md)
  - 將多個譜面組的自訂打擊音效合併到一個譜面組
  - 將 MIDI 轉換為按鍵音效
- **Hitsound Preview Helper**
  - 根據物件的位置放置打擊音效
  - 輕鬆建立與 Hitsound Studio 相容的打擊音效譜面
- **Rhythm Guide**
  - 從譜面擷取節奏，做為製作打擊音效時的參考
- **Geometry Dashboard**
  - 在編輯器上即時疊加幾何圖形，供製圖時參考
- **Combo Colour Studio**
  - 輕鬆建立色彩跳轉
  - 在譜面之間複製色彩跳轉
- **Sliderator**
  - 在滑條中途改變滑條速度
  - 建立加速或減速的連打
- **Auto-fail Detector**
  - 偵測 2B 風格譜面中的 auto-fail
  - 自動修正 auto-fail
- **Pattern Gallery**
  - 建立並分享製圖圖樣收藏
  - 在譜面之間複製圖樣
- **Mapset Merger**
  - 將多個譜面組合併成一個大型譜面組
- **Tumour Generator**
  - 沿著滑條邊緣加入各種形狀
  - 以全新方式設計完整滑條
- **Slider Picturator**
  - 將圖片轉換成滑條並放入譜面
