Par défaut, Mapping Tools s'ouvre sur l'écran de démarrage. Celui-ci affiche le journal des modifications de l'application et la liste des dernières beatmaps utilisées avec Mapping Tools. Vous pouvez aussi accéder à cet écran depuis le menu de navigation.

En haut de l'écran se trouve une barre bleue avec le bouton de navigation, les menus et l'affichage de la _beatmap sélectionnée_. Il s'agit de la beatmap sur laquelle la plupart des outils de mapping vont intervenir.

Le bouton de navigation ouvre un menu à gauche, qui permet d'accéder à toutes les pages de Mapping Tools. Une barre de recherche permet de saisir le nom d'une page ; appuyez sur `Entrée` pour ouvrir le premier résultat. Vous pouvez ouvrir le menu de navigation à tout moment avec `Ctrl+K`.

### Fichier {#file}

Le menu **Fichier** contient des commandes pour sélectionner, charger et enregistrer vos fichiers de beatmap.

- **Ouvrir une beatmap** ouvre l'explorateur de fichiers pour sélectionner une ou plusieurs beatmaps et les définir comme beatmap sélectionnée.
- **Ouvrir la beatmap actuelle** définit comme beatmap sélectionnée celle qui est actuellement sélectionnée dans le client _osu!_.
- **Créer une sauvegarde** crée une sauvegarde de la beatmap sélectionnée.
- **Charger une sauvegarde** ouvre l'explorateur de fichiers pour sélectionner une sauvegarde à charger dans la beatmap sélectionnée.
- **QuickUndo** charge dans la beatmap sélectionnée la dernière sauvegarde non périodique.
- **BetterSave™ la beatmap actuelle** enregistre la beatmap actuellement ouverte dans l'éditeur _osu!_ en arrondissant les coordonnées au lieu de les tronquer.

### À propos {#about}

Le menu **À propos** fournit des informations et des liens utiles sur Mapping Tools.

- **Ouvrir le dossier des sauvegardes** ouvre le dossier qui contient toutes les sauvegardes créées par Mapping Tools.
- **Ouvrir le dossier de Mapping Tools** ouvre le dossier qui contient tous les fichiers créés par Mapping Tools, comme les paramètres, les sauvegardes et les exportations.

### Projet {#project}

Le menu **Projet** n'est visible que lorsque vous consultez l'écran de l'un des outils de mapping. Il contient des commandes pour enregistrer et charger les paramètres propres à l'outil.
