Le développement principal de Mapping Tools se déroule dans ces deux dépôts GitHub :

### Mapping Tools

L'application de bureau principale de Mapping Tools.

https://github.com/OliBomby/Mapping_Tools

### Site web de Mapping Tools

Le site web que vous consultez. Il partage les connaissances sur Mapping Tools avec le monde entier.

https://github.com/mappingtools/mappingtools.github.io

## Projets obsolètes

Ces projets ne sont plus activement développés, mais peuvent encore être utiles.

### Mapping Tools Core

Le paquet back-end de Mapping Tools destiné aux développeurs .NET. Il permet à d'autres programmes d'utiliser les fonctionnalités de Mapping Tools.

https://github.com/OliBomby/Mapping_Tools_Core

### Mapping Tools Web

La version web de Mapping Tools. Elle utilise Mapping Tools Core et est entièrement multiplateforme.

https://github.com/misakura-rin/mapping-tools-web
