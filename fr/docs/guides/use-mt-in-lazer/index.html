Utiliser Mapping Tools dans osu! lazer

osu! lazer utilise un flux de travail différent de celui d'osu! stable pour modifier les beatmaps. Mapping Tools peut modifier les fichiers de beatmap des deux clients. Dans lazer, utilisez la fonction de modification externe et gardez à l'esprit que certaines fonctions ont des limites.

Utiliser Mapping Tools dans osu! lazer​

Dans l'éditeur osu! lazer, cliquez sur Fichier > Modifier en externe. Un dossier temporaire contenant tous les fichiers du mapset en cours de modification sera créé. Mapping Tools détectera automatiquement ce dossier et le définira comme beatmap sélectionnée. Une fois les modifications terminées avec Mapping Tools, cliquez sur Terminer la modification et importer les changements ; osu! lazer importera alors vos changements.

Compatibilité​

Toutes les fonctions de Mapping Tools ne fonctionnent pas dans osu! lazer. Cette section récapitule la compatibilité des fonctions de Mapping Tools.

Les fonctions qui utilisent Editor Reader ne fonctionnent pas dans osu! lazer. Il est donc recommandé de désactiver Editor Reader dans les Préférences si vous comptez utiliser uniquement osu! lazer.

Général​

  • ❌ Ouvrir la beatmap actuelle ne fonctionne pas.
  • ❌ Heure actuelle de l'éditeur ne fonctionne pas.
  • ❌ Objets sélectionnés ne fonctionne pas.
  • ✅ Créer une sauvegarde fonctionne.
  • ✅ Charger une sauvegarde fonctionne.
  • ✅ Les trajectoires de slider comprenant plusieurs types de segments sont entièrement prises en charge.

Outils​

  • ❌ Geometry Dashboard ne fonctionne pas. Il dépend d'Editor Reader.
  • ✅ Hitsound Copier fonctionne.
  • 🔶 Hitsound Studio fonctionne, mais les références aux échantillons importés et aux beatmaps cessent de fonctionner lorsque le dossier temporaire est supprimé.
  • ✅ Pattern Gallery fonctionne.
  • ✅ Property Transformer fonctionne.
  • ✅ Sliderator fonctionne, mais il ralentit fortement l'éditeur lazer.
  • ✅ Tumour Generator 2 fonctionne.
  • 🔶 Auto-fail Detector fonctionne, mais le mécanisme d'échec automatique n'existe pas dans lazer.
  • ✅ Combo Colour Studio fonctionne.
  • ✅ Hitsound Preview Helper fonctionne.
  • ✅ Map Cleaner fonctionne.
  • ✅ Mapset Merger fonctionne.
  • ✅ Metadata Manager fonctionne.
  • ✅ Rhythm Guide fonctionne.
  • ✅ Slider Completionator fonctionne.
  • ✅ Slider Merger fonctionne.
  • 🔶 Slider Picturator fonctionne, mais le slider image ne s'affiche pas dans lazer.
  • ✅ Timing Copier fonctionne.
  • ✅ Timing Helper fonctionne.

À propos de la compatibilité future avec lazer​

osu! lazer étant activement développé, son client et son format de fichier sont susceptibles de changer, ce qui pourrait empêcher Mapping Tools de fonctionner. Si vous rencontrez un problème avec Mapping Tools dans lazer qui ne figure pas dans cette liste, signalez-le avec À propos > Signaler un problème.
