Map Cleaner

Map Cleaner 会清理已选谱面中的无用绿色时间点，也能对整张谱面执行其他实用操作。

Map Cleaner 会通过重建所有时间点来清理谱面。它会先记录每个时间点的影响，然后以结构化的方式重新建立时间点。这意味着绿色时间点会自动重新对齐到使用它们的物件上，同时移除不必要的更改。除非启用了其他功能，否则谱面和打击音基本不会发生变化；改动主要体现在编辑器中。

谱面信息设置​

这些设置决定 Map Cleaner 是否会从时间点中移除某些内容。如果想谨慎处理，可以勾选所有设置，这样被移除的内容最少。

  • Map uses volume changes in sliders：勾选后，表示你有意在滑条期间更改音量，因此 Map Cleaner 不应移除这些更改。
  • Map uses sampleset changes in sliders：勾选后，表示你有意在滑条期间更改采样组或采样索引，因此 Map Cleaner 不应移除这些更改。
  • Map uses volume changes in spinners：勾选后，表示你有意在转盘期间更改音量，因此 Map Cleaner 不应移除这些更改。

其他功能​

除了常规清理之外，Map Cleaner 还可以执行以下操作：

  • Resnap objects：清理谱面时重新对齐所有打击物件和滑条尾端。重新对齐时会使用节拍细分设置。
  • Resnap bookmarks：使用默认的重新对齐方式重新对齐所有书签。如果书签使用了异常节拍细分，建议取消勾选此项。
  • Remove unused samples：移除谱面集中所有谱面和故事板都未使用的音频采样。可由谱面皮肤指定的采样会被忽略。
  • Remove muting：移除音量为 5% 的打击音上的所有音量更改和自定义索引更改。如果时间点音量为 5%，该处的音量更改和自定义索引更改都会被移除。
  • Mute unclickable hitsounds：将音量设为 5%，静音来自无需玩家主动输入的打击物件的所有打击音。只有圆圈、滑条起点和长按物件起点会发声。此功能有助于了解谱面的节奏或演奏效果。

重新对齐​

重新对齐会将物件吸附到时间线上最近的刻度，并向下取整为整数。如果打击物件时间之后 10 毫秒内有红线，则会改为吸附到该红线，以防物件被吸附到红线前 3 毫秒的刻度上。

滑条尾端有两种重新对齐方式。第一种方式会获取滑条持续时间，并将其改为最接近节拍细分整数倍的时长。这类似于在原版 osu! 编辑器中对滑条使用 Ctrl+Shift+S。

如果滑条期间或滑条结束后 20 毫秒内出现红线，则会使用第二种方式。它会根据新时间，将滑条结束时间吸附到最近的刻度。这样生成的滑条时长会是整数，但由于时间线刻度的取整，实际长度会略有偏差。

所有转盘尾端和长按物件尾端也会使用第二种方式重新对齐。

如果已选谱面使用 osu! mania 模式，重新对齐时还会将音符的 X 坐标移到列中央，并将 Y 坐标设为 192。

时间线​

运行 Map Cleaner 时，会显示一条小型时间线，标记程序对时间点所做的所有更改。

  • 红线表示已移除的时间点。
  • 橙线表示已更改的时间点。
  • 绿线表示新增的时间点。

如果某个时间点只是移动了位置，时间线会在其旧位置显示红线，在新位置显示绿线。

你可以双击时间线上的任意线条，跳转到编辑器中的对应时间。
