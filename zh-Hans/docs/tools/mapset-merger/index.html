Mapset Merger

Mapset Merger 可以将多个谱面集合并为一个大型谱面集。

此工具会自动解决文件冲突：尽可能将文件移至不同子文件夹，并重新构建自定义打击音的采样组。遗憾的是，谱面皮肤和自定义转盘音效无法合并，因为谱面没有明确引用这些文件，因此它们始终会影响整个谱面集。

添加谱面集​

点击右下角的加号按钮，即可添加谱面集。新谱面集会自动填入已选谱面的谱面集信息。按住 Shift 再点击加号，则会使用 osu! 客户端当前打开的谱面集。

要合并的所有谱面集都会显示在列表中。每个谱面集都有名称和根文件夹路径。合并后，程序会根据名称对文件进行分类，因此请为每个谱面集使用简洁且互不重复的名称。你可以在列表中双击路径进行编辑，也可以点击显示的浏览按钮，在文件资源管理器中选择路径。

导出​

点击运行按钮即可合并谱面集，并将文件导出到 Export path 文件夹。请确保此文件夹已存在，否则程序会报错。

勾选 Move storyboard to .osu 后，Mapset Merger 会将谱面集内所有 .osb 文件的内容移至 .osu 文件中。这样故事板就会专属于各自的谱面，不会应用到合并后谱面集中的其他谱面。合并使用不同故事板的谱面集时，此选项很有用；但请谨慎使用：如果某个谱面集中的故事板文件较大，而且有多个难度，数据量会随之倍增，产生体积很大的 .osu 文件。
